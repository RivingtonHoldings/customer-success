# Setup check

Run this at the start of every session. It takes a few seconds and answers three questions a teammate cannot easily answer themselves: am I working on the latest files, can Claude reach Notion and Intercom, and does the help center mirror look healthy. The teammate is not technical; every line of the report should make sense to someone who has never used a terminal.

Do the four steps in order and print one short line per step as you go, then the closing paragraph. Do not skip a step because an earlier one failed; report each independently so the teammate sees the whole picture.

## Step 1: Pull the latest from main

Run:

```
git pull origin main
```

Translate the result:

- "Already up to date" becomes "You already had the latest files."
- A list of changed files becomes "Pulled N updated files from your teammates," and name any file under `docs/standards/` or `workstreams/*/docs/` since those change how the team works.
- A merge conflict (the output mentions CONFLICT) becomes "Two people changed the same file. I will sort it out." Then resolve it, preferring the remote version for mirror files under `docs/help-center/` (the mirror is regenerated by `/sync-help-center` anyway) and asking the user for anything under `workstreams/` or `docs/standards/`.
- A network or authentication error becomes "I could not reach GitHub. You are working from your local copy, which may be behind." Suggest checking the internet connection and, if it mentions authentication, messaging Leo.

If the working tree has uncommitted changes that block the pull, say "You have unsaved work from a previous session," list the files, and offer to commit it first with a short message.

## Step 2: Confirm the connector tools

The Notion and Intercom tools come from claude.ai connectors. Their exact names are in `docs/connector-tools.md`; the two prefixes are:

- Notion: `mcp__c9a24086-67bc-4593-858e-3f11e07b6f9d__`
- Intercom: `mcp__eff8e27b-83eb-43ee-befe-90e26bf3b57b__`

Check whether tools with each prefix are available in this session. Tools may be deferred (listed by name but not loaded); if the harness offers a tool search, load one representative tool per connector to prove it is callable: `notion-search` for Notion and `list_articles` for Intercom. Do not call any tool that writes.

Report each connector on its own line:

- Present: "Notion: connected." / "Intercom: connected."
- Missing: "Notion: not connected. To fix it, open claude.ai in your browser, click your name, then Settings, then Connectors, and click Connect next to Notion. Then start a brand new session here and run /setup-check again." Same wording for Intercom.
- Present but the representative call fails with an authorization or reconnect error: "Intercom: connected, but it needs to be reconnected. In claude.ai, go to Settings, then Connectors, click Intercom, choose Disconnect, then Connect again. Start a new session afterward."

If the tools are present but their prefix differs from the one in `docs/connector-tools.md`, say so plainly: the connector works for this teammate, but `.claude/settings.json` will prompt for permission on every call until the names are updated. Suggest telling Leo and include the prefix you found.

## Step 3: Smoke test the help center mirror

Run the bundled script from the repo root:

```
bash .claude/skills/setup-check/scripts/recent-articles.sh baldwin 5
```

It prints the five most recently updated Baldwin articles from `docs/help-center/baldwin/` as "updated date, title, state" plus the last sync time from `sync-state.json`. Show those lines to the teammate.

- If the folder holds no articles, say "The Baldwin mirror is empty. Run /sync-help-center to fill it." This is normal on a fresh clone before the first sync has been committed.
- If the last sync was more than seven days ago, add "The mirror was last refreshed on <date>. Run /sync-help-center if you need today's articles."

## Step 4: Closing status

End with one paragraph, plain language, no bullet points, that says whether the teammate is ready to work and what, if anything, they should do first. Examples:

- All good: "You are ready to go. Your files are current as of just now, Notion and Intercom are both connected, and the Baldwin mirror was refreshed two days ago. Ask me for whatever you need."
- One problem: "You can start working, but Intercom is not connected, which means I cannot read conversations or articles until it is. Connect it in claude.ai under Settings, then Connectors, and start a new session. Everything else checked out."

Never end with a question. The teammate should be able to read the paragraph and either start working or follow one clear instruction.

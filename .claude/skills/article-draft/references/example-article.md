# Print your search results as a PDF
<!-- Sentence case section heading, task-based, begins on the Search page -->

Print uses the search you already built, so set up your filters and columns the way you want them to appear before you start.

### Steps:

1. Go to **Search**
2. Apply filters to define the listings you want to print
3. Click **Actions**
4. Click **Print**

# Choose a layout and save as PDF

The print window belongs to your browser, so the exact wording varies a little between Chrome, Safari, and Edge.

- Select **Landscape** for a horizontal page. This gives your columns more room across the width.
- Select **Portrait** for a vertical page.
- Click **Print** to send the results to a printer, or set the destination to **Save as PDF** to create a file you can share or keep.

# Control which columns appear

Your printout matches the columns in your Search results table, in the same order. Adjust them before you print:

- Drag and drop column headers to reorder columns
- Click **+** to add a column
- Remove columns you do not need for this printout

Every column you display has to fit across the page, so a long column list prints narrow and can be hard to read. Trim to the columns that matter for the conversation you are printing for.

> 📖 Learn how to save a column layout as a template in [Customize Your Search View](https://intercom.help/perchwell-help-center-baldwin/en/articles/11962073-customize-your-search-page).

# Control which listings appear

Print includes every listing in your current search results. To leave a listing out, hide it before you print:

### Steps:

1. Select the checkbox next to the listings you want to leave out
2. Click **Actions**
3. Select **Hide**

Hidden listings no longer appear in your current search results, which means they will not appear in your printout either.

# Things to Know

- Print always reflects the current results table. Re-run or adjust the search first if the listing set is not right.
- Hiding a listing affects only your current results; it does not remove the listing from Perchwell.

## Why this article is the specimen

- Title is Title Case, task-based, no gerund.
- Intro follows the exact "In this article:" plus "You will learn how ..." pattern with bolded surfaces.
- Every section heading is sentence case and specific enough to scan.
- Steps blocks use `### Steps:`, one action per step, no terminal periods, bolded UI targets.
- Voice is imperative and matter-of-fact. No "you can," no "allows you to," no marketing adjectives.
- System behavior is explained where the reader would otherwise be surprised (the print window belongs to the browser; every column has to fit; hidden listings drop out of the printout).
- One primary goal. Column templates are linked, not re-explained.

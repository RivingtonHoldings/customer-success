# Help Center Style Rules

Moved. The single source of truth is `docs/standards/content-standards.md`, written and approved on September 4, 2026. Read that instead.

This file used to hold the bundled fallback rules for when `docs/standards/content-standards.md` was a placeholder. It is kept only as a pointer so older references do not dead-end. Do not add rules here; a second copy of the rulebook is how the two drifted apart in the first place.

Three rules changed when the standard was written, so anything that still cites this file is out of date:

- The `## In this article:` heading was retired. Articles now open with a jobs-to-be-done paragraph: "Use this article to \<outcome 1\>, \<outcome 2\>, and \<outcome 3\>."
- The "Connect with our Support Team" footer was retired. Intercom renders Related Articles and a feedback prompt itself.
- Emoji-led callouts were retired. Callouts lead with a bold **Note:**, **Important:**, or **Tip:** label, which is what Intercom says Fin reads.

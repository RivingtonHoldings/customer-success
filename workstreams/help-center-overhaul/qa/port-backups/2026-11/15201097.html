How do I customize my report fields and layouts?

Some fields are customizable, like the report columns in the Quick CMA. Full layout customization isn't available in Perchwell today, but the team is exploring options to allow more complete field customization in a future update.

What does "include exact address" mean when creating a Quick CMA?

When you enable this option, the recipient of the PDF can select the address directly, and it will take them to the Listing Details Page.

Can I create a Quick CMA for residential lease properties?

Yes. Filter for the residential lease property type, and the process is the same as it is for for-sale listings.

How can I control what sections clients see in reports?

You can collapse sections using the arrow next to each one. Collapsed sections will not appear in the full report shared with clients.

Can I customize the layout of my reports?

Some layout options are available depending on the report type, but not every field position can be customized at this time. We are actively exploring additional layout options and will share updates as they become available.

What fields can I include in a Quick CMA or Subject Property CMA?

You can customize your CMA report to display listing fields directly on the report. Once the report is built, you can share it by email or download and print it to distribute to clients.

To add or update the fields included in your report, go to the customization step in the CMA editor and select the data points you want to display for each listing.

The following fields are available to include:

  • $/SQ FT

  • Property Tax

  • Lot Size

  • HOA/YR

  • Baths

  • Days on Market

  • Property Type

  • Acreage

  • City

  • SQ FT

  • Status Date

  • List/Sold

  • Year Built

  • MLS ID

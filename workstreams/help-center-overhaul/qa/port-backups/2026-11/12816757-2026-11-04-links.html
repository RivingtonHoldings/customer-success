Use this article to print a Full Report from a Listing Detail Page, create a Full Report from your search results, choose the agent or client version, reorder listings, email, print, or download the report, and find it later in your Report library.

When to use a Full Report

A Full Report prints the entire Listing Detail Page for one or more listings. Before you print the full report, there is an option to print an agent version, a client version, or both.

  • Share detailed listing information with a client

  • Prepare materials for showings or listing presentations

  • Send a full property packet to an agent or colleague

  • Print property documentation for an in-person meeting

For a one-page summary with a QR code, see Create One Page Reports. The Full Report omits the property images besides the primary image, as well as the Mortgage and Tax calculators. The Full Report is capped at 50 listings per report. If a Full report has more than 50 listings, it will automatically be sent to your email as a report.

Print a Full Report from a Listing Detail Page

Print a Full Report for one listing from its Listing Detail Page.

Steps:

  1. Click the arrow next to a section to hide it from the full report.

  2. Click Actions in the upper right

  3. Select Print full report

  4. Select For agent or For client in the Print report window

  5. (Optional) Clear Include Listing History

  6. Click Print

The Full Report opens in a print preview window, where you print it or save it as a PDF (Portable Document Format) file. Any section you collapsed on the Listing Detail Page is also collapsed in the Full Report.

Create a Full Report from your search results

Create a Full Report for one or more listings from the Search page.

Steps:

  1. Click the Results tab

  2. Select the checkboxes next to the listings you want

  3. Click Actions

  4. Select Create a Report

  5. Select Full Report

The report window moves to the Customize Report step with your selected listings.

Choose the agent or client version of the Full Report

Choose who the Full Report is for in the Print report window or on the Customize Report step:

  • For agent: Includes agent-only information, such as showing instructions.

  • For client: Includes your contact information and space for client notes.

  • Both: Creates two Full Reports, one for agents and one for clients. Available on the Customize Report step only.

Include Listing History adds the listing's History section to the Full Report, which means status and price changes print with the listing. Include Listing History is selected by default.

Reorder or remove listings in the Full Report

Reorder or remove listings in the Listings section of the Customize Report step.

  • Drag a listing up or down to change its place in the Full Report

  • Click the X to the right of a listing to remove it from the Full Report

  • Click View Listing to open the listing

To add listings, create a new Full Report from the Search page.

Email, print, or download the Full Report

Email, print, or download the Full Report from the Generate Report step of the report window. Click Next on the Customize Report step to open it, or click Previous to change a setting.

Email the Full Report

Email the Full Report to one or more recipients from the Generate Report step.

Steps:

  1. Enter one or more email addresses in the Emails field

  2. Enter a subject in the Email Subject field

  3. Edit the text in the Message field

  4. Click Email Report

Each recipient receives the Full Report by email. The Email Subject field has no default text.

Print the Full Report

Print the Full Report from the Generate Report step.

Steps:

  1. Click Print

  2. Choose your printer and settings in your browser's print dialog

  3. Click Print in the print dialog

Your browser sends the Full Report to your printer.

Download the Full Report as a PDF

Click Download on the Generate Report step to save the Full Report to your computer as a PDF file.

Find a past Full Report in your Report library

Open your Report library to find saved Full Reports.

Steps:

  1. Hover over your profile icon in the upper right corner

  2. Click Report library

Your Report library opens with your saved reports, including Full Reports printed from a Listing Detail Page. Search for a report by the recipient's email address.

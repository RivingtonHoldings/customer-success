Create a Tag from the Tags page

Create a new Tag when you want to start tracking or sharing listings.

Steps:

  1. Click Tags in the navigation bar.

  2. Click New Tag.

  3. Enter a Tag Name.

  4. (Optional) Open the Contacts dropdown and select one or more clients to attach.

    1. Note: Attaching a client to the Tag will unlock reactions on listings in the public Tags page

  5. Click Save.

A Tag can be created with no client attached, and you can always add a client at a later time.

Add a client to an existing Tag

Attach a client to a Tag you already created, once you know who it's for.

Steps:

  1. Click Tags in the navigation bar.

  2. Find the Tag and open its Edit (pencil) menu.

  3. Open the Contacts dropdown and select a contact, or click + New Contact to create one.

  4. Click Save.

Once a client is added to a Tag, they can't be removed from it, so double check before saving.

Editing your Tag Name

To edit the name of your Tag, go to your Tags Page.
Click on the Edit icon of your Tag.
​

Edit the Name section to what you want.
​

Note: Clients cannot be removed from Tags because Tags are public links that do not require a Perchwell account to be viewed. Perchwell does not let you remove a client from a tag to avoid the confusion that the client will no longer be able to view the tag after removing them. If you wish to revoke the ability for viewers to see the tag, simply delete the tag using the Delete button in the Edit (pencil) menu.

Use this article to find what the search filters, listing tools, Dashboard features, client tools, and account settings you knew in a legacy platform are called in Perchwell. Key Workflow Changes explains how those workflows have changed.

Perchwell names for search filters and tools

This table matches search filters and tools from a legacy platform to their Perchwell names.

Legacy platform term

Perchwell name

Class

Property Type, a Quick Filter on the Search page

Property Type

Subtype, listed under each type in the Property Type filter

Active New Construction

Active status, with Construction Status set to Under Construction

Spreadsheets

Column templates, in the Columns menu above your search results

Power Search

Universal Search Bar, the Search field in the upper right of the top navigation

Financial Amortizer

Mortgage & Tax, on the Listing Detail Page

For more information:

  • Filter Your Search by Property Types covers selecting property types and subtypes.

  • Listing Statuses in Perchwell defines each listing status, including new construction.

  • Customize Your Search View explains how to create and apply column templates.

  • Universal Search Bar explains how to find a listing, agent, or contact from any page.

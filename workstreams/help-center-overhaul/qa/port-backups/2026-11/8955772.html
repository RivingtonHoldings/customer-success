When to use an Itinerary report

Use an Itinerary report to plan and share a property tour schedule with listing details and maps.

  • Plan a tour with multiple properties

  • Prepare for buyer showings

  • Organize open house visits

  • Share a clear schedule and property details with a client

Itinerary creation (Search or Tags)

Choose the starting point that matches how you selected your listings.

Start from Search

Use this option when you are selecting listings from search results.

Steps:

  1. Open Search page

  2. Switch to the listings results by clicking Search

  3. Select the checkboxes next to the listings you want to include

  4. Click Actions

  5. In the drop down, click Create a Report

  6. Select Itinerary

Tour schedule

After the itinerary editor opens, add the schedule details for the tour.

Add the appointment date (required)

  • Enter the Appointment Date

Add optional schedule details

  • Add a Start time

  • Add an End time

  • Add a Meeting location

Tour stop details

Add appointment details for each listing so your itinerary stays accurate.
​

Steps:

  1. Click a listing address in the itinerary editor

  2. Update the details

    • Add an appointment time

    • Add notes for the property

  3. Toggle the map view on or off

  4. Click Done

After you review all listings, click Next

Itinerary customization

Before you generate the report, select the details you want recipients to see.

Select who the itinerary is for (optional)

  • In Prepare For, select a contact from your Contacts list

Select the details to include:

  • Include brokerage

  • Include agent name

  • Include agent phone number

  • Include My contact information

  • Include open house information

  • Include exact address

  • Include large map

  • Include neighborhood

  • Include cross streets

Choose how listing links open

Set what happens when someone clicks a listing link in the itinerary.

  • Select Open in Perchwell (clients must log in)

  • Select Open externally with your branding

Itinerary sharing

After you review your itinerary, choose how you want to share it.

Email

Steps:

  1. Select Email

  2. Enter the recipient email address

  3. Update the subject line

  4. Review the message body and make edits as needed

  5. Click Email Report

You and the recipient both receive a copy.

Print

Steps:

  1. Select Print

  2. In your browser’s print dialog, choose your printer and settings

  3. Click Print

Download

Steps:

  1. Select Download

  2. Wait for the PDF to generate

  3. Save the file to your device

Tips

  • Remove or reorder listings before you share.

  • Toggle maps on or off for each listing.

  • Find saved itineraries in your Report Library.

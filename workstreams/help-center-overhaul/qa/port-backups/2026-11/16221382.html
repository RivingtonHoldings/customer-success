Considerations

  • If a listing falls outside of the Saved Search criteria, it is removed from the tag automatically. The tag always reflects the Saved Search's current results, not its history.

  • If you want a listing to persist in the Tag regardless of what happens in the Saved Search (e.g. a listing has a price decrease that pushes it outside of the search criteria), tag it individually (see How to Add Listings to a Tag) or wait for the client to react to it. Directly-added listings stay until you remove them. Reacted listings stay for as long as that reaction is active.

  • Filters you've added just for your own tracking stay visible to you only, even if the search is shared.

Link existing Saved Searches while creating a Tag

Steps:

  1. Click Tags in the navigation bar.

  2. Click New Tag.

  3. Enter a Tag Name.

  4. (Optional) Open the Contacts dropdown and select one or more clients to attach.

  5. Click Next

  6. Navigate to the Add search results to Tag

  7. Select one or more Saved Searches from the dropdown

  8. (Optional) Enabling Alerts

    1. If you have attached a client to the Tag, toggle the Alerts for Perchwell to automatically notify your client via email of activity in the Tag.

    2. If you have not attached a client to the Tag, toggle the Alerts for Perchwell to automatically notify you via email of activity in the Tag.

  9. Click Save.

Link an existing saved search to an existing Tag

Attach a Saved Search you created to a tag you already created.

Steps:

  1. Navigate to the Tags tab in the navigation bar.

  2. Click the Tag (pencil) menu in the Actions column of the Tag you want to attach a Saves Search to.

  3. Find the Add search results to Tag section and click the dropdown.

  4. Select the Saved Search you would like to attach to the Tag.

  5. (Optional) Enabling Alerts

    1. If you have attached a client to the Tag, toggle the Alerts for Perchwell to automatically notify your client via email of activity in the Tag.

    2. If you have not attached a client to the Tag, toggle the Alerts for Perchwell to automatically notify you via email of activity in the Tag.

  6. Click Save to confirm your selections.

This workflow links the Saved Search to the client's existing tag. If that client doesn't have a tag yet, set one up first (see How to Create a Tag).

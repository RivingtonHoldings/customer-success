1. Tag a listing from the Property Detail page

Add one listing to a Tag while you're already looking at it.

Steps:

  1. Open the listing's Property Detail page.

  2. Click Add to Tag.

  3. Select an existing Tag, or click + New Tag to create one.

  4. Click Save.

2. Tag multiple listings from your search results

Add a batch of listings to a Tag straight from a search, instead of opening each one individually.

Steps:

  1. Run a search.

  2. Select the listings you wish to Tag using the checkboxes.

  3. Click Actions on the top right of the results

  4. Click Share in the actions bar.

  5. Click the Tags tab

  6. Select an existing Tag, or create a new one.

  7. Click Save.

Synchronize your Tags page with the listings in a Saved Search

Attach a saved search to a Tag so every matching listing rolls into it as the search refreshes; see How to Add a Saved Search to a Tag for the full setup.

  • New listings that match the search are added to the Tag going forward.

  • You don't need to add these listings by hand.

  • All listings that populate in the Tag from a Saved Search are temporary and tied to the search. If a listing no longer meets the Saved Search criteria, it will automatically be removed from the Tag. For example, if a listing has a price change that no longer meets the price range in the Saved Search, it will automatically disappear from the Saved Search results and the Tag page.

Note: A listing with a reaction persists in the Tag for as long as that reaction stays active, even if it later stops matching the search it came from. If the client undoes the reaction, the listing can drop back out unless it's also covered by a direct add or a still-matching search.

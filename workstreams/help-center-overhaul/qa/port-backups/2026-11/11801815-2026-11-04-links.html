Use this article to turn on AI Scribe in a listing, generate a Listing description from the details you entered, and edit and check the description before you submit the listing.

This video is applicable to all customers

Turn on AI Scribe in the listing form

Turn on AI Scribe in the Remarks/Directions section of Add/Edit, the form where you enter a new listing or update an existing one.

Steps:

  1. Click Manage Listings in the top navigation bar

  2. Click Add New Listing, or open the listing you want to edit

  3. Click Remarks/Directions in the section list on the right

  4. Turn on the AI Scribe toggle under Listing description

The AI Scribe toggle is off by default. When you turn it on, the Length, Tone, and Focus dropdowns open below it, with a fair housing notice above them.

Tip: Fill in the listing details before you turn on AI Scribe. AI Scribe writes from the information you enter, so a more complete listing gives it more to work with.

Generate a Listing description with AI Scribe

Generate a Listing description with AI Scribe by choosing from the three dropdowns below the AI Scribe toggle:

  • Length: Select Short, Medium, or Long.

  • Tone: Select Descriptive, Energetic, Neutral, Professional, or Time-sensitive.

  • Focus: Select one or more features for the description to highlight: Building amenities, Location, Rooms, Unit amenities, or Views.

Click the orange Apply changes button to generate the description. The description appears in the Listing description field, which holds the listing's public remarks. AI Scribe changes no other field.

To try a different version, change Length, Tone, or Focus and click Apply changes again.

Important: Each AI Scribe description replaces the text already in the Listing description field, including text you typed or edited. Copy any text you want to keep before you click Apply changes.

Edit and check an AI Scribe description before you submit

Edit the AI Scribe description in the Listing description field before you submit the listing. The Listing description field holds up to 2,000 characters.

Check the description for:

  • Accuracy against the listing details you entered

  • Fair housing compliance

AI Scribe writes descriptions designed for Fair Housing Act compliance. Verifying and approving the final text remains your responsibility as the listing agent, as the fair housing notice above the dropdowns states. Click the X on the notice to close it.

The text stays in the Listing description field when you turn off the AI Scribe toggle. Add and Edit Listings explains how to save a draft or submit the listing.

# Message Clients in Perchwell

**Description:** Message invited clients in Perchwell, share listings in Messages from Search or a listing, and review how clients react to them.

Use this article to message clients you have invited to Perchwell: start a conversation in Messages, share listings in a message from Search, a Listing Detail Page, or a Tag, review client reactions in Shared Properties, and find new messages.

https://app.arcade.software/share/lg7AYrZuU0oHjQSW5AKv

## Invite a client before you message them in Messages

Invite a client to Perchwell before you message them. Messages works only with clients you have invited. [Invite Clients to Perchwell](http://support.perchwell.com/baldwin/en/articles/11373895-invite-clients-to-perchwell) walks through sending an invitation from the Contacts page.

To send listings to someone you have not invited, share them by email, text message, or public link instead. [Share Multiple Listings in Perchwell](http://support.perchwell.com/baldwin/en/articles/13903326-share-multiple-listings-in-perchwell) covers each option.

## Start a new conversation in Messages

Start a conversation with an invited client from the Messages page.

### Steps:
1. Click Messages in the top navigation
2. Hover over Contacts in the left panel
3. Click the pencil icon
4. Select the contact you want to message
5. Enter your message
6. Click the Send icon

The new conversation appears in Messages.

## Message a contact from the Contacts page

Click the Chat in Messages chat bubble icon next to a contact on the Contacts page. Messages opens with that contact.

## Share listings in Messages

Share listings with an invited client in Messages from the Search page, a Listing Detail Page, or a Tag. Each way opens the Share window, where a message is required and is limited to 1,000 characters.

### Share listings from Search in Messages

Send one or more listings from your search results to an invited client in Messages.

### Steps:
1. Click Search in the top navigation
2. Select the checkbox next to each listing you want to share
3. Click Actions
4. Select Share via Message
5. Select a contact
6. Enter a message in Include a message
7. Click Send

The listings are sent in a message, and the conversation appears in Messages.

> Screenshot placeholder: the Search page with listings selected and the Actions menu open, Share via Message highlighted | Alt text: The Search page with listings selected and the Actions menu open, showing Share via Message.

### Share a listing from a Listing Detail Page in Messages

Send one listing to an invited client in Messages from its Listing Detail Page.

### Steps:
1. Click Actions on the upper right of the Listing Detail Page
2. Select Send as in-app message
3. Select a contact
4. Enter a message in Include a message
5. Click Send

The listing is sent in a message, and the conversation appears in Messages.

> Screenshot placeholder: the Actions menu on a Listing Detail Page with Send as in-app message highlighted, cropped to exclude the agent photo | Alt text: The Actions menu on a Listing Detail Page, with Send as in-app message under Share, between Share and Share via Text.

### Share a listing from a Tag in Messages

Send a listing from a Tag in Messages from the listing's full Listing Detail Page.

### Steps:
1. Click Tags in the top navigation
2. Open the Tag that holds the listing
3. Click the listing to open its listing details
4. Click View within Perchwell, or open the listing in a new tab
5. Click Actions on the upper right of the Listing Detail Page
6. Select Send as in-app message
7. Select a contact
8. Enter a message in Include a message
9. Click Send

The listing is sent in a message, and the conversation appears in Messages.

## Review client reactions in Shared Properties

Review how a client reacted to the listings you shared in Messages from Shared Properties in your conversation with them. Clients react to each shared listing with Like, Maybe, or Reject. Filter the shared listings by reaction:

- All: Shows every listing you shared with the client.
- Undecided: Shows listings the client has not reacted to yet.
- Maybe: Shows listings the client marked Maybe.
- Liked: Shows listings the client liked.
- Rejected: Shows listings the client rejected.

### Steps:
1. Click Messages in the top navigation
2. Click the contact's name to open the conversation
3. Click Shared Properties
4. Select a filter

Shared Properties shows the listings that match the filter. Click a listing to open the message thread where you shared it.

## Get notified of new messages and find them in Messages

Find new messages from invited clients in Messages. Perchwell alerts you to a new message in three ways:

- Email: Perchwell emails you when a client sends you a new message.
- Green dot: A green dot on Messages in the top navigation means you have a new message.
- Push notification: The Perchwell mobile app sends a push notification when push notifications are turned on. [Messages Overview](http://support.perchwell.com/baldwin/en/articles/14786130-messages-overview) covers Messages in the mobile app.

### Steps:
1. Click Messages in the top navigation
2. Find a conversation with a notification badge
3. Click the contact's name to open the conversation

The conversation opens with the client's new message.

## Things to Know

- Conversations in Messages cannot be deleted.
- When you message a client, Perchwell emails them from [no-reply@perchwell.com](mailto:no-reply@perchwell.com) with your name as the sender. Replies to that email go to your conversation with the client in Messages.
- Invited clients send and receive messages from Messages in their client portal, the workspace where you collaborate with invited clients. It looks similar to your Messages page.

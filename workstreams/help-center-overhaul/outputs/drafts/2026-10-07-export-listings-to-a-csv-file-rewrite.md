# Export Listings to a CSV File

**Description:** Export listings from your search results to a CSV file, and create export templates that save your preferred fields and field order.

Use this article to export listings to a CSV (comma-separated values) file, choose which fields to include, and create or manage export templates.

> Video placeholder: selecting listings on the Search page, selecting Export CSV in the Actions menu, creating an export template, and clicking Export

## Export selected or all listings to a CSV file

Export selected listings to a CSV file from the Results tab of the Search page. Search results load 30 listings at a time. To export all search results, scroll down until every listing has loaded. The count above the results shows how many have loaded.

### Steps:

1. Select the checkbox next to each listing you want to export, or the checkbox above them to select all
2. Click Actions
3. Select Export CSV
4. Select Quick export or an export template
5. Click Export

The CSV file downloads to your computer and includes only the listings you selected. Open the downloaded file in your spreadsheet app, such as Microsoft Excel or Apple Numbers.

> Screenshot placeholder: the Search page with one listing selected and the Actions menu open, Export CSV highlighted | Alt text: The Search page with one listing selected and the Actions menu open, showing Export CSV.

## Choose Quick export or an export template

Select Quick export or a template in the Export window to choose which fields appear in the CSV file:

- Quick export: Select, clear, or reorder fields for the current export without saving a template.
- MLS Template: Includes the export fields set by your MLS and is marked Master. To customize it, copy the template and edit your copy.
- Your export templates: Select a template you created to export its saved fields and field order.

> Screenshot placeholder: the Export window with Quick export selected, showing the Search columns field and the Selected fields with drag handles | Alt text: The Export window with Quick export selected, showing a column search field, Select all and Deselect all, and checked fields.

## Create an export template

Create an export template to save the fields and field order you want in a CSV file. The field list includes any field available when adding a listing.

### Steps:

1. Click the plus icon next to Template in the Export window
2. Enter a name in the Template Name field
3. *(Optional)* Turn on Set as default list to select this template by default for future exports
4. *(Optional)* Enter a field name in the Search columns field
5. Select a field to include it in the export, or clear it to remove it
6. *(Optional)* Click Select all or Deselect all to change every field at once
7. Drag the handle next to a field to change its position
8. Click Save as template

The template is saved and appears below MLS Template in the Export window.

> Screenshot placeholder: the New Template form in the Export window, with the Template Name field, the Set as default list toggle, the Search columns field, and checked fields with drag handles | Alt text: The New Template form in the Export window, with a name field, a default toggle, a column search field, and fields with checkboxes and drag handles.

## Create multiple export templates or match a search results column template

Create multiple export templates to save the fields and field order for each type of export. For example, create separate templates for residential and land listings.

Search results column templates and export templates are separate. To export the same fields in the same order as a search results column template, create an export template with matching fields and field order.

[Customize Your Search Results View](https://app.notion.com/p/3e68b9e0143881f3a934e295ac7a21b5) covers columns and column templates in search results.

## Edit, copy, or delete an export template

Edit, copy, or delete a saved export template from the Export window. Select the template to display its actions in the upper right.

> Screenshot placeholder: a saved export template open in the Export window, with the trash icon, the copy icon, and the Edit template button in the upper right | Alt text: A saved export template in the Export window showing 8 selected columns, with trash, copy, and Edit template buttons.

- Edit: Click Edit template to change the template name, fields, or field order. Click Save template when finished.
- Copy: Click the copy icon to create a new template with the same fields. The new template is named Copy of followed by the original template name, such as Copy of MLS Template.
- Delete: Click the red trash icon, then click Delete in the Delete this template window to remove it from the Export window.

> **Important:** A deleted export template cannot be restored.

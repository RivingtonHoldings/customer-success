# Add Listings to a Tag

**Description:** Add one or more listings to a Tag from Search results, a Listing Detail Page, or the Dashboard, and notify the Tag's contacts.

Use this article to add listings to one or more Tags and notify contacts about them. A Tag groups listings in one place and has its own public link. Members who came from a legacy platform may know Tags as Listing Carts.

https://www.loom.com/embed/3dcc11372b634f93a35935b9d7785f8e

## Add listings to new or existing Tags

Add listings to new or existing Tags from the Share window. Open it from any of these:

- Search results: Select the checkbox next to each listing, click Actions, then select Share.
- Preview: Click a listing in your search results to preview it, click Listing Actions, then select Share.
- Listing Detail Page: Click Actions in the upper right, then select Share.
- Dashboard: Click the tag icon next to a listing in the Listings widget. The icon appears when the widget is set to MLS Listings, Brokerage Listings, or Office Listings.

> Screenshot placeholder: Show the Share window for one listing with the Select a Tag menu under via Tag | Alt text: The Share 1 Listing window with the Select a Tag menu under via Tag, the via Public Link section, and Cancel and Next buttons.

### Steps:
1. Select one or more Tags from the Select a Tag menu under via Tag
2. Click Next
3. Click Add Listings, or Add Listings | Send if any selected Tag is under Invited

> Screenshot placeholder: Show the Listings added! window after adding one listing | Alt text: The Listings added! window showing the added listing and a row with the Tag's link, its listing count, and copy and open icons.

The listings are added to each selected Tag. A confirmation window shows the number of listings and a link to each Tag.

To review the listings before adding them, click Edit next to Listings in the Share via Tag window. In the Edit Listings window, drag listings or click the arrows to reorder them. Click the trash can icon to remove one, or the box-and-arrow icon to open the full listing.

To add listings to a Tag you have not created yet, click Create New Tag in the Select a Tag menu.

## Notify a Tag's contacts about new listings

Contacts on a Tag are notified about new listings only after they have been invited to the Tag. [How to Share a Tag](http://support.perchwell.com/baldwin/en/articles/16221617-how-to-share-a-tag) explains how to invite contacts. After you click Next in the Share window, each selected Tag appears under Invited or Uninvited:

- Invited: The contacts on these Tags receive your message. Edit the required Subject and Message fields or select a template from the Template menu, then click Add Listings | Send.
- Uninvited: The listings are added without notifying the contacts on these Tags. Select Invite contacts to Tag and notify to send each contact a Welcome to Your Tag email with a View Tag button.

> Screenshot placeholder: Show the Share via Tag window with Tags under both Invited and Uninvited | Alt text: The Share via Tag window with Tags under Invited and Uninvited, the Invite contacts to Tag and notify checkbox, and the Subject and Message fields.

If a "Listings were added, but no eligible clients could be notified." message appears, every selected Tag was under Uninvited, so no contacts were notified.

## Add listings to a Tag automatically with a saved search

Link a saved search to a Tag to add matching listings automatically. Those listings leave the Tag when they stop matching the search. A listing you add from the Share window stays until you remove it. [How to Link a Saved Search to a Tag](http://support.perchwell.com/baldwin/en/articles/16221382-how-to-link-a-saved-search-to-a-tag) explains how to set one up and how a client's reaction keeps a listing in the Tag.

## Remove a listing from a Tag

Remove a listing from a Tag on its Listing Detail Page or on the Tags page:

- Listing Detail Page: Click the x next to the Tag's name below Views. The listing leaves the Tag even if a contact liked or disliked it.
- Tags page: Click the Edit tag pencil icon next to the Tag, then click Edit next to Listings and notes. Click the trash can icon next to the listing, then click Save in the Edit Tag window. Listings from a linked saved search have no trash can icon. [How to Link a Saved Search to a Tag](http://support.perchwell.com/baldwin/en/articles/16221382-how-to-link-a-saved-search-to-a-tag) explains how to remove one.

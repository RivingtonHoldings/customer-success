# Tags in the Perchwell Mobile App

**Description:** Add listings to Tags from Search or a Listing Detail Page, view tagged listings, and copy a Tag's link in the Perchwell mobile app.

Use this article to add listings to Tags, view tagged listings, copy a Tag's public link, turn Tag alerts on or off, and edit or delete a Tag in the Perchwell mobile app.

## Add listings to a Tag in the mobile app

Add listings to one or more Tags from the Search page or a Listing Detail Page in the Perchwell mobile app. Members who came from a legacy platform may know Tags as Listing Carts.

Start from either place:

- Search page: Tap Listings at the bottom of the Search page and tap the checkbox on each listing you want. Then tap Actions and Add tag.
- Listing Detail Page: Tap the three-dots icon in the upper right, then tap Add Tag.

### Steps:

1. Enter a Tag's name in the search field, or scroll to find the Tag
2. Tap each Tag you want to add the listings to
3. *(Optional)* To add the listings to a new Tag, enter its name in the search field and tap Create tag

The listings are added to a Tag as soon as you tap it. Contacts in each Tag are notified of the new listings.

## View tagged listings on the My Tags screen

Tap Tags in the bottom navigation of the Perchwell mobile app to open the My Tags screen. To find a Tag, enter its name in the Search tags field at the top. Tags are grouped in two lists:

- Shared with client: Tags with at least one client added, whether or not you have sent the Tag.
- Other Tags: Tags with no clients.

> Screenshot placeholder: Show the My Tags screen in the Perchwell mobile app with Tags under Shared with client and Other Tags, using Tag names that carry no client names | Alt text: The My Tags screen in the Perchwell mobile app, with the Search tags field, Tags in two lists, and the Show items in selected tags button.

### Steps:

1. Tap each Tag whose listings you want to view
2. Tap Show items in selected tags

The Tagged items page opens with the listings from every Tag you selected.

## Copy a Tag's public link in the mobile app

Tap the three-dots icon next to a Tag on the My Tags screen, then tap Copy link to copy the Tag's public link. A "Link copied to clipboard" message appears. Paste the link in a text or an email, or post it on your website.

Clients open the Tag's public page from the link with no Perchwell login. [Share a Tag with Clients](https://app.notion.com/p/3fe8b9e0143881e390ded9fb4761452c) explains what clients see on the public page and how to invite contacts to a Tag.

## Turn Tag alerts on or off in the mobile app

Turn Tag alerts on or off with the bell icon next to a Tag on the My Tags screen in the Perchwell mobile app. Tag alerts email you when listings in the Tag change. Clients in the Tag do not receive them.

The three-dots menu next to a Tag also has Turn off alerts, or Turn on alerts when the Tag's alerts are off.

To choose which changes send an alert, tap the three-dots icon next to the Tag, then tap Edit tag. Under Alerts, turn Price increase, Price decrease, or Status change on or off. All three are off by default.

[Create and Edit a Tag](https://app.notion.com/p/3fb8b9e0143881349fd7ce5e4749fa5a) explains what each Tag notification covers.

## Edit a Tag's name in the mobile app

Tap the three-dots icon next to a Tag on the My Tags screen, then tap Edit tag. Enter the new name in the Tag name field. [confirm: the button that saves your changes]

## Delete a Tag in the mobile app

Delete a Tag from its Edit tag screen in the Perchwell mobile app.

### Steps:

1. Tap the three-dots icon next to the Tag on the My Tags screen
2. Tap Edit tag
3. Tap Delete Tag in the lower left of the Edit tag screen
4. Tap Delete in the window that asks "Are you sure you want to delete this tag?"

The Tag is removed from the My Tags screen, and its public link stops working. The listings stay in Perchwell.

> **Important:** A deleted Tag cannot be recovered.

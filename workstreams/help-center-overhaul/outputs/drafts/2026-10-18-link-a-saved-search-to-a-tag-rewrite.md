# Link a Saved Search to a Tag

**Description:** Link saved searches you've already created to a Tag so their listings are added or removed automatically as search results change.

Use this article to link saved searches to a Tag, keep specific listings in the Tag, and unlink a saved search. A Tag groups listings in one place and has its own public link. Members who came from a legacy platform may know Tags as Listing Carts.

> Video placeholder: Show linking two saved searches to an existing Tag, from clicking the Edit tag pencil icon through the "Tag updated." message

## Link saved searches to a new or existing Tag

Save a search first, then link it to a new or existing Tag from the Tags page. There is no Tag option when you save a search. [Manage Your Saved Searches](http://support.perchwell.com/baldwin/en/articles/8955646-manage-your-saved-searches) explains how to save one. Start from either of these:

- New Tag: Click New Tag in the upper right, then enter a name in the Name field.
- Edit tag: Click the Edit tag pencil icon in the Actions column next to an existing Tag.

### Steps:
1. Click Add next to Saved searches
2. Click the Saved searches field
3. Enter the saved search's name in the Search by name or contact field
4. Select the checkbox next to each saved search you want to link
5. Click Add again
6. Click Create for a new Tag, or Save for an existing Tag

> Screenshot placeholder: Show the Add saved search window with two saved searches selected | Alt text: The Add saved search window with two saved searches selected in the Saved searches field, each listed below with its listing count.

The Tag includes the listings from each linked saved search right away.

## How saved search listings update in a Tag

Listings from a linked saved search update in a Tag as the search results change. New matching listings are added automatically, and listings that no longer match are removed.

To keep a listing in the Tag after it stops matching the saved search, add it to the Tag individually. [How to Tag Individual Listings](http://support.perchwell.com/baldwin/en/articles/16221347-how-to-tag-individual-listings) explains how. A listing a contact likes or dislikes also stays in the Tag as long as the reaction remains.

When Tag notifications are on, listings added automatically from a linked saved search trigger an email, just like listings added individually.

## See which Tag listings come from a saved search

Check the label under each listing on the Tag's public page to see whether it came from a saved search:

- From Saved Search: The listing comes from a linked saved search.
- Shared by: You added the listing individually.

In the Edit Tag window, click Edit next to Listings and notes. Listings added individually appear under Added by you, and listings from each saved search are grouped under the search's name.

> Screenshot placeholder: Show the Listings and notes window with listings added by you above listings from a saved search | Alt text: The Listings and notes window with listings under Added by you, then listings grouped under a saved search's name, each with a Note for client field.

## Remove one saved search listing from a Tag

Remove one saved search listing from a Tag by hiding it in the saved search and saving the search. The listing stays in the Tag until you save. [Actions Menu Options on the Search Page](http://support.perchwell.com/baldwin/en/articles/13623271-multi-listing-actions-on-the-search-page) explains how to hide listings.

The trash can icon in the Listings and notes window removes only listings added individually. A listing added from the saved search stays in the Tag if a contact liked or disliked it. It leaves the Tag once you or the contact removes the reaction on the Tag's public page.

## Unlink a saved search from a Tag

Unlink a saved search in the Edit Tag window to remove listings added from that saved search.

### Steps:
1. Click the Edit tag pencil icon in the Actions column next to the Tag
2. Click the x next to the saved search's name under Saved searches
3. Click Save

> Screenshot placeholder: Show the Edit Tag window with two linked saved searches under Saved searches | Alt text: The Edit Tag window with two saved searches under Saved searches, each with an x to unlink it, and the Listings and notes count.

A "Tag updated." message appears, and listings added from the saved search are removed from the Tag. Listings a contact liked or disliked remain.

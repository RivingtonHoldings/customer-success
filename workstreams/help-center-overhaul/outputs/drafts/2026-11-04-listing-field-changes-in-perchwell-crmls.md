# Listing Field Changes in Perchwell

**Description:** Learn which Matrix listing fields were renamed or are not stored in Perchwell, including Township, mixed use subtypes, and more.

Use this article to find what Matrix listing fields and statuses are called in Perchwell, see which property subtypes Perchwell does not store, and understand what a $0 or 0 value means.

## Community replaces Township

The Matrix Township field is called Community in Perchwell. To search by Community, open the Filters tab and find the Community section, which holds the Subdivision name and Subdivision name other fields. On a listing, the Subdivision name other field appears in the Land & Lot section.

## Temporarily off-market listings have a different status name in CRMLS dashboards

Listings with a temporarily off-market status appear as Hold in Perchwell. CRMLS (California Regional Multiple Listing Service) dashboards call the same listing status Temporarily Off Market.

## Mixed use, rooms for rent, and hotel or motel subtypes are not stored in Perchwell

Perchwell does not store the Mixed Use, Rooms for Rent, or Hotel/Motel property subtypes. Listings with these subtypes may not appear when filtering by property subtype. To find them, search without applying a property subtype filter.

## A $0 or 0 value means the MLS did not report a value

A $0 HOA (homeowners association) fee, $0 tax, or 0 days on market means the MLS (multiple listing service) did not report a value. On a listing, read these values as not reported, not as an actual zero.

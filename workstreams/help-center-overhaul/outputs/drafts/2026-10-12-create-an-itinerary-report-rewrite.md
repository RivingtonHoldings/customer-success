# Create an Itinerary Report

**Description:** Create an Itinerary report from your search results, add tour times and notes for each stop, and email, print, or download it.

Use this article to create an Itinerary report from your search results, set the tour date, times, and stops, choose what the Itinerary report shows, email, print, or download it, and find it later in your Report library.

https://app.arcade.software/share/F4S2DbVoarPRynwV6qBG

## When to use an Itinerary report

An Itinerary report is a tour schedule for the listings you plan to visit, with appointment times, notes, and maps.

- Plan a tour of multiple properties
- Prepare for buyer showings
- Organize open house visits
- Share a tour schedule and property details with a client

## Create an Itinerary report from your search results

Create an Itinerary report from the listings you select on the Search page.

### Steps:

1. Click the Results tab
2. Select the checkboxes next to the listings you want
3. Click Actions
4. Select Create a Report
5. Select Itinerary

The report window moves to the Customize Report step with your selected listings.

To build an Itinerary report from listings saved to a Tag, find them on the Search page first. Enter their MLS IDs in the MLS ID filter, separated by commas. Then select them in your results and create the report.

## Plan the tour in the Itinerary report

Plan the tour on the first screen of the Customize Report step, under Itinerary Details and Listings.

### Set the tour date and times for the Itinerary report

Set the tour date, times, and meeting place under Itinerary Details. Date is the only required field.

- Date: Enter the day of the tour.
- Start Time: Enter when the tour starts.
- End Time: Enter when the tour ends.
- Meeting Location: Enter where you meet your client.

### Add appointment times and notes to each listing in the Itinerary report

Add an appointment time and notes to each tour stop in the Listings section.

### Steps:

1. Click a listing's address
2. Enter a time in the Appointment Time field
3. *(Optional)* Enter notes in the Notes field
4. *(Optional)* Clear Include map to leave the map out for this listing
5. Click Done

Repeat these steps for each listing on the tour. The Notes field holds up to 400 characters, and Include map is selected by default.

> Screenshot placeholder: a listing open in the Listings section with the Appointment Time and Notes fields filled in | Alt text: A tour listing open on the Customize Report step, with the Appointment Time and Notes fields, the Include map checkbox, and the Done button.

### Reorder or remove listings in the Itinerary report

Reorder or remove tour stops in the Listings section.

- Drag a listing up or down to change its place on the tour
- Click the X to the right of a listing to remove it from the Itinerary report
- Click View Listing to open the listing

To add listings, create a new Itinerary report from the Search page.

## Customize the Itinerary report

Click Next below the tour listings to choose what the Itinerary report shows.

### Add your client's name to the Itinerary report

Select a client in the Select from clients or type client's name field, or type a name. The Itinerary report header then reads Prepared for, followed by the client's name. The field is optional.

### Choose the listing details in the Itinerary report

Select the details each listing shows in the Itinerary report under Select fields to show in itinerary:

- Brokerage: The listing brokerage's name.
- Agent name: The listing agent's name.
- Agent phone number: The listing agent's phone number.
- My contact info: Your contact information.
- Open house: Open house information.
- Exact address: The full street address.
- Large map: A large map.
- Neighborhood: The listing's neighborhood.
- Cross streets: The listing's cross streets.

Every detail except Agent name and Agent phone number is selected by default.

### Choose how listing links open in the Itinerary report

Choose what happens when a recipient clicks a listing in the Itinerary report:

- Open links in Perchwell (clients must log in): Opens the listing in Perchwell, which means the client needs a Perchwell login to view it.
- Open links externally with your branding: Opens the listing on a page with your branding.

Open links externally with your branding is selected by default.

## Email, print, or download the Itinerary report

Click Next on the Customize Report step to open the Generate Report step of the report window. Click Previous to change a setting.

### Email the Itinerary report

Email the Itinerary report to one or more recipients from the Generate Report step.

### Steps:

1. Enter one or more email addresses in the Emails field
2. *(Optional)* Edit the subject in the Email Subject field
3. *(Optional)* Edit the text in the Message field
4. Click Email Report

Each recipient receives the Itinerary report, and Perchwell copies you on the email. The Email Subject field is set to Our Itinerary by default, and the Message field holds a short default message.

### Print the Itinerary report

Print the Itinerary report from the Generate Report step.

### Steps:

1. Click Print
2. Choose your printer and settings in your browser's print dialog
3. Click Print in the print dialog

Your browser sends the Itinerary report to your printer.

### Download the Itinerary report as a PDF

Click Download on the Generate Report step to save the Itinerary report to your computer as a PDF (Portable Document Format) file.

## Find a past Itinerary report in your Report library

Open your Report library to find Itinerary reports you created earlier.

### Steps:

1. Hover over your profile icon in the upper right corner
2. Click Report library

Your Report library opens with your saved reports, including Itinerary reports. Search for a report by the recipient's email address.

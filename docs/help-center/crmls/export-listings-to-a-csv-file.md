# Export Listings to a CSV File

Use this article to export listings to a CSV (comma-separated values) file, choose which fields to include, and create or manage export templates.

# Export selected or all listings to a CSV file

Export selected listings, or every listing in your search results, to a CSV file from the Results tab of the Search page.

## Steps:
1. Select the checkbox next to each listing you want to export, or leave all listings unselected to export every listing
2. Click Actions
3. Select Export CSV
4. Select Quick export or an export template
5. Click Export

The CSV file downloads to your computer with the listings you selected, or every listing in your search results if none were selected. Open the downloaded file in your spreadsheet app, such as Microsoft Excel or Apple Numbers.

# Choose Quick export or an export template

Select Quick export or a template in the Export window to choose which fields appear in the CSV file:
- Quick export: Select, clear, or reorder fields for the current export without saving a template.
- MLS Template: Includes the export fields set by your MLS and is marked Master. To customize it, copy the template and edit your copy.
- Your export templates: Select a template you created to export its saved fields and field order.

# Create an export template

Create an export template to save the fields and field order you want in a CSV file. The field list includes any field available when adding a listing.

## Steps:
1. Click the plus icon next to Template in the Export window
2. Enter a name in the Template Name field
3. Select the fields you want to include in the export
4. Drag the handle next to a field to change its position
5. Click Save as template

The template is saved and appears below MLS Template in the Export window.

The New Template form also includes these options:
- Set as default list: Turn on to select this template by default for future exports.
- Search columns: Enter a field name to find it in the list.
- Select all and Deselect all: Click to select or clear every field at once.

# Create multiple export templates or match a search results column template

Create multiple export templates to save the fields and field order for each type of export. For example, create separate templates for residential and land listings.

Search results column templates and export templates are separate. To export the same fields in the same order as a search results column template, create an export template with matching fields and field order.

[Customize Your Search Results View](https://support.perchwell.com/crmls/en/articles/18234037-customize-your-search-results-view) covers columns and column templates in search results.

# Edit, copy, or delete an export template

Edit, copy, or delete a saved export template from the Export window. Select the template to display its actions in the upper right.
- Edit: Click Edit template to change the template name, fields, or field order. Click Save template when finished.
- Copy: Click the copy icon to create a new template with the same fields. The new template is named Copy of followed by the original template name, such as Copy of MLS Template.
- Delete: Click the red trash icon, then click Delete in the Delete this template window to remove it from the Export window.

> **Important:** A deleted export template cannot be restored.

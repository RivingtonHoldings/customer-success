# View Shared Saved Searches

# Saved Search overview

A saved search is a search with filters already set, like location, price range, and property type.
- View the newest listings that match your criteria
- See updates automatically as new listings hit the market
- Skip rerunning the same search

# Shared Saved Search access

### Steps:
1. Click **Search** in the top navigation
2. Click the **Saved Searches button**
3. Select the saved search you want to view

# Results navigation

## Listing access
- Switch to the results view by clicking **Search**
- Click a listing to view photos and property details

## Filter updates

Adjust filters in the **Filters** view to narrow or expand your results.

> 💡 Saved searches update automatically. You do not need to recreate them.

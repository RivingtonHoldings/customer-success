# What Changed When You Moved to Perchwell

Use this article to find where the features and tasks you know from Matrix now live in Perchwell, and how to do each one now.

# Search changes in Perchwell

These Search changes in Perchwell happen on the Search page and in the Universal Search Bar.

## Type a subdivision name instead of picking from a dropdown

In Matrix, you picked a subdivision from a dropdown. In Perchwell, type the subdivision name in the Subdivision name field under Community on the Filters tab.

## Set each location filter on its own

Set each location filter on its own in Perchwell. City, County, and MLS Area are in the Location section of the Filters tab, and schools and subdivisions have their own sections. Results match every filter you set. In Matrix, each pick narrowed the next list in the county, city, MLS area, school, and subdivision filters.

[Create a Search with Filters](https://support.perchwell.com/crmls/en/articles/18233998-create-a-search-with-filters) explains how filters combine.

## Association and Source filters are not in Perchwell

Matrix had a filter for Association or Source. Perchwell has no filter that matches it.

## See the map, filters, and results on one screen

The map, filters, and results share one screen in Perchwell. In Matrix, the criteria page came first and the map was on a separate tab. The map and results update as you set filters. [Search Page Overview](https://support.perchwell.com/crmls/en/articles/18234118-search-page-overview) covers each part of the page.

## Drive time replaces radius search

Search by drive time with the Commute filter instead of by radius. In Matrix, a radius search from a point had a distance-by-road column. Perchwell results have no distance column.

[Filter Your Search with Map Tools](https://support.perchwell.com/crmls/en/articles/18234069-filter-your-search-with-map-tools) explains how to set an origin and a travel time.

## Search one MLS number at a time in the Universal Search Bar

In Matrix, you entered a space-separated list of MLS numbers in the Power Bar. In Perchwell, the Universal Search Bar finds one MLS number at a time. To look up multiple listings at once, open the Search page and enter the MLS IDs in the MLS ID filter, separated by commas.

[Universal Search Bar](https://support.perchwell.com/crmls/en/articles/18234136-universal-search-bar) explains how to find a listing, agent, or contact from any page.

## Type an address as it appears

In Perchwell, the Universal Search Bar matches the address as you type it. In Matrix, the Power Bar was strict on street type: Vivian Rd worked and Road did not.

## Saved searches replace recent search history

A saved search keeps a search you plan to rerun. Name it so you tell it apart from similar searches, such as separate lot and land searches. To reopen a saved search, find it in the Saved Searches widget on the Dashboard and sort by recently updated.

[Manage Your Saved Searches](https://support.perchwell.com/crmls/en/articles/18234059-manage-your-saved-searches) explains how to save, find, and sort your saved searches.

## Template Search replaces the Quick Search widget

Matrix had a Quick Search widget on the Dashboard. In Perchwell, save a search with your most-used criteria and set it as your Template Search. Every new search starts with that search's filters.

[Create a Template Search](https://support.perchwell.com/crmls/en/articles/18234015-create-a-template-search) explains how to set one up.

# Listing entry stays in Matrix

Add/Edit is not in Perchwell for CRMLS (California Regional Multiple Listing Service). Keep entering and editing listings in Matrix.

A new or edited listing reaches Perchwell through CRIB, the CRMLS data source. The last step takes about 5 minutes. [Why Listings and Market Data Can Look Different in Perchwell](https://support.perchwell.com/crmls/en/articles/18247275-why-listings-and-market-data-can-look-different-in-perchwell) explains why a listing may look different in Perchwell.

# Client collaboration changes in Perchwell

Client collaboration in Perchwell centers on saved searches, Tags, and Messages.

## Review alerts before clients see them

In Perchwell, review matches before clients see them by sending the saved search alerts to yourself first, then tagging the listings you approve. Matrix Concierge mode let you approve matches before the client saw them. Tagged listings appear in the client's Tags.

[Tags Page Overview](https://support.perchwell.com/crmls/en/articles/18233327-tags-page-overview) explains how to save and share listings with Tags.

## See the saved searches you shared with a client

In Perchwell, the Contacts page shows the saved searches you shared with a client. The client sees the same saved searches in their Perchwell account. In Matrix, you could see what a saved search sent to a client.

## Find new listings on the Tags page

The Tags page shows which listings are liked, disliked, and New to you. In Matrix, saved searches showed an indicator for new or un-actioned listings.

## Clients move from OneHome to the Perchwell client portal

[Find OneHome Features in the Perchwell Client Portal](https://support.perchwell.com/crmls/en/articles/18247272-find-onehome-features-in-the-perchwell-client-portal) lists each OneHome feature with its Perchwell client portal match.

# Dashboard changes in Perchwell

The Dashboard is the page Perchwell opens to.

## Hot Sheets replace Market Watch

Hot Sheet is the Perchwell name for Matrix Market Watch. Add Hot Sheets to your Dashboard to track new and updated listings. [Add a Hot Sheet to the Dashboard](https://support.perchwell.com/crmls/en/articles/18232986-add-a-hot-sheet-to-the-dashboard) walks through creating one.

## Saved searches and Hot Sheets replace My Listings quick filters

In Matrix, My Listings had quick filters such as My Active and My Pending. In Perchwell, build and save one search for each filter, then create a Hot Sheet for each saved search.

## Print a Hot Sheet from its results list

In Perchwell, print the Hot Sheet results from the results list, or take a screenshot.

## Open Hot Sheets on a computer or in your phone's browser

Open Hot Sheets on a computer, or log in to Perchwell in your phone's browser.

# Search Analytics charts save with a saved search

Save a search to keep its Search Analytics charts. In Matrix, you saved analytics as presets or dashboard widgets. [Analytics Page Overview](https://support.perchwell.com/crmls/en/articles/18234722-analytics-page-overview) covers the Analytics reports.

# Perchwell reports replace Matrix reports

Perchwell reports replace every Matrix report except Photo Single Line, Input Order, Hotsheet print, and President's Sales Club. Every Perchwell report starts from a search. [Find the Perchwell Report That Replaces Each Matrix Report](https://support.perchwell.com/crmls/en/articles/18247271-find-the-perchwell-report-that-replaces-each-matrix-report) lists each Matrix report with the Perchwell report that replaces it.

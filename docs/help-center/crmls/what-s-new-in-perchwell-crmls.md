# What's New in Perchwell | CRMLS 🚀

>

# 2.3.2026 Updates
>
>
> - Share multiple listings with clients directly from the search page via email or with one public link.
> - Generate multiple one page and full page reports directly on the Search page.

>

# 1.29.2026 Updates | Mobile
>
>
> - Agents can now view precise property boundaries and their live location directly on the listing details page in the mobile app, making it easy to verify lot lines during showings.
> - "List Date" on coming soon listings has been relabeled to "Start Showing" to clearly indicate when properties will hit the market.

>

# 12.9.2025 Updates
>
>
> - Newly added contacts are now automatically added as recipients when sharing listings by email.
> - Rental listings now display clearer monthly pricing and no longer show irrelevant mortgage calculators.
> - Agent branding now appears on Full Reports for clients just like it does on One Page Reports, ensuring consistent personal branding across all client communications.
> - Perchwell's updated color system creates a more visually consistent, accessible platform experience with improved readability and contrast.

>

# 12.2.2025 Updates | Mobile
>
>
> - Enhanced map search that displays individual property pins when zoomed in, giving agents a clearer view of exact property locations.
> - Fixed several key interface elements including profile picture updates and more appropriate labeling for property details.

>

# 11.18.2025 | Updates
>
>
> - The Agent & Office card on Property Details pages now displays comprehensive listing agent information including license numbers, contact details, and office information.

>

# 11.11.2025 Updates
>
>
>
> **Smarter Maps, Clearer Insights**
> - Maps on the Search and Property Details pages now default to a hybrid satellite view combining aerial imagery with clear property boundaries.
>
> **Sharper, Ready-to-Share Reports**
> - Full page reports are enhanced to look polished for clients. They highlight key information and fit neatly on standard paper..
>
> **Lot Cost Per Sq. Ft. (Commercial)**
> - Commercial properties have a new field which displays lot cost per square foot, Helping you assess property value faster and guide clients with confidence.
>
> **New Financials Section on Property Details**
> - Evaluate investment potential at a glance with the Financials sub-section, including Investment Info, Annual Income, and Expenses.

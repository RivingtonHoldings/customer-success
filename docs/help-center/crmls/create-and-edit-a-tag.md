# Create and Edit a Tag

Use this article to create, edit, or delete a Tag. A Tag groups listings in one place and has its own public link. Members who came from a legacy platform may know Tags as Listing Carts.

# Create a Tag from the Tags page

Create a Tag from the Tags page to collect listings for a client or for your own tracking.

## Steps:
1. Click New Tag in the upper right
2. Enter a name in the Name field
3. *(Optional)* Enter a description in the Description field
4. Click Create

The new Tag appears on the Tags page with My Tag in the Status column until a contact is added. The Tag's name and description appear on its public page.

To create a Tag while sharing listings from Search, click Create New Tag in the Select a Tag menu. [Add Listings to a Tag](https://support.perchwell.com/crmls/en/articles/18233325-add-listings-to-a-tag) explains how to add listings to a Tag from Search.

# Create a Tag for a new contact

Create a Tag for a contact while adding them to your contacts. In the Create New Contact window, turn on the Create Tag toggle, then click Create.

[![image](https://perchwell.intercom-attachments-1.com/i/o/trq7czv5/2788126782/d5473e6e76a720762e64b1905ae3/upload_7928055838177501993.png)](https://perchwell.intercom-attachments-1.com/i/o/trq7czv5/2788126782/d5473e6e76a720762e64b1905ae3/upload_7928055838177501993.png?expires=1793900700&signature=7ba43a24f797a49454c6995391479978a56325db1b30b27b0d6baa99ef7aa368&req=dicvHsh8m4ZXW%2FMW1HO4zYE8B15qhnZgvzkLASk0g4SI%2BtbmVoUWyA2yD35C%0A3RhHPYfXB1mJAFSdIqM%3D%0A)

Perchwell creates a Client Tag named for the contact. The contact's initials appear next to the Tag's name on the Tags page.

[Contacts Page Overview](https://support.perchwell.com/crmls/en/articles/18232916-contacts-page-overview) explains how to add a contact.

# Tag settings for reactions, saved searches, listings, and notifications

Set a Tag's reactions, saved searches, listings, and notifications when you create it. To change them later, click the Edit tag pencil icon next to the Tag on the Tags page.
- Reactions: Turn on Reactions to let contacts like or dislike listings on the Tag's public page. Reactions are on by default. The like and dislike icons appear only when the Tag has at least one contact.
- Saved searches: Click Add to link one or more saved searches to the Tag. [Link a Saved Search to a Tag](https://support.perchwell.com/crmls/en/articles/18233314-link-a-saved-search-to-a-tag) explains how saved search results appear in a Tag.
- Listings and notes: Shows how many listings the Tag holds. Click Edit to add notes, reorder listings, open a full listing, or remove a listing. After removing one, click Save in the Edit Tag window. Add new listings to the Tag from Search or a listing's page.
- Tag notifications: Turn on Tag notifications to receive emails about listings in the Tag. An email goes out when a listing is added or has a Price Increase, Price Decrease, or Status Change. Tag notifications are on by default, with all three changes selected. Emails go to you, and the Tag's contacts are copied.

# Edit a Tag's name, description, or settings

Change a Tag's name, description, or settings from the Edit Tag window on the Tags page.

## Steps:
1. Click the Edit tag pencil icon in the Actions column next to the Tag
2. Change the name, description, or settings
3. Click Save

[![image](https://perchwell.intercom-attachments-1.com/i/o/trq7czv5/2788126859/defbf59cd2c4ab28543092141bd0/upload_10241985283136301349.png)](https://perchwell.intercom-attachments-1.com/i/o/trq7czv5/2788126859/defbf59cd2c4ab28543092141bd0/upload_10241985283136301349.png?expires=1793900700&signature=1a7a9a21d20ac83661b4d6bfa3bcea2cbb2ed8bdfd89f2281879e20900bc47d0&req=dicvHsh8m4laUPMW1HO4zTfcnddNrUI0cVGEYUWlwFOQIWAJ3cUwzaRUuyY1%0AkHOUPNFsqYL6gybvSqA%3D%0A)

Changes to the Tag's name or description also appear on its public page.

# Duplicate a Tag

Duplicate a Tag on the Tags page to copy its listings and settings into a new Tag with its own public link. Contacts and client reactions are not copied.

## Steps:
1. Click the Edit tag pencil icon in the Actions column next to the Tag
2. Click Duplicate
3. *(Optional)* Change the name, description, or settings in the Duplicate Tag window
4. Click Duplicate

[![image](https://perchwell.intercom-attachments-1.com/i/o/trq7czv5/2788126875/59ba7012a55b4fd18a1a83ecf129/upload_9657563268648894513.png)](https://perchwell.intercom-attachments-1.com/i/o/trq7czv5/2788126875/59ba7012a55b4fd18a1a83ecf129/upload_9657563268648894513.png?expires=1793900700&signature=df940c4f3aef77fd3dc386834bb48515e353c1ff06f2ddcf35302a2de3b1ab38&req=dicvHsh8m4lYXPMW1HO4zYKm8WXVHjByRX77iV95MZJZ9SDXTJZRKkyQDWIc%0Abyiun9yU1QZOrDCLk2A%3D%0A)

A "Tag duplicated." message appears, and the duplicate is added to the Tags page with My Tag in the Status column. Its name ends in Copy unless you changed it. To add contacts to the duplicate, click Send in the Actions column next to it.

# Add contacts to an existing Tag

Add contacts to an existing Tag when you send it from the Tags page. Click Send in the Actions column next to the Tag, then add the contacts in the Share your tag window. [Share a Tag with Clients](https://support.perchwell.com/crmls/en/articles/18233319-share-a-tag-with-clients) explains how to send a Tag and invite contacts.

> **Important:** A contact cannot be removed from a Tag after you save it. To stop sharing the Tag, delete it. Its public link then stops working for everyone.

# Clear all listings from a Tag

Clear all listings from a Tag on the Tags page to empty it without deleting it.

> **Important:** Clearing a Tag also removes its saved searches and your contacts' likes and dislikes. This cannot be undone.

## Steps:
1. Click the Edit tag pencil icon in the Actions column next to the Tag
2. Click Clear All Listings
3. Click Clear All to confirm

[![image](https://perchwell.intercom-attachments-1.com/i/o/trq7czv5/2788126892/c3f9ffbe99ce5790cab56a6e9dd6/upload_7309671784767528746.png)](https://perchwell.intercom-attachments-1.com/i/o/trq7czv5/2788126892/c3f9ffbe99ce5790cab56a6e9dd6/upload_7309671784767528746.png?expires=1793900700&signature=204a913b8babaa4b47123ed9b9af41cacdcc4ba68fe21146447efa5f743f2cae&req=dicvHsh8m4lWW%2FMW1HO4zR95TbfELQCrAjAQ8lxiNtrUwEGukKSAZNNrLa1P%0A%2F10CgF5lmZOV4f9HOKE%3D%0A)

An "All listings have been cleared." message appears. The Tag stays on the Tags page with 0 listings and keeps its name, reactions, and notification settings.

# Delete a Tag

Delete a Tag on the Tags page when you no longer need it or want to stop sharing it.

> **Important:** Deleting a Tag cannot be undone.

## Steps:
1. Click the Edit tag pencil icon in the Actions column next to the Tag
2. Click Delete in the lower left of the Edit Tag window
3. Click Delete again to confirm

[![image](https://perchwell.intercom-attachments-1.com/i/o/trq7czv5/2788126910/a1dcb4c9dc2a07ed2cb98fe93c33/upload_12569165352726814497.png)](https://perchwell.intercom-attachments-1.com/i/o/trq7czv5/2788126910/a1dcb4c9dc2a07ed2cb98fe93c33/upload_12569165352726814497.png?expires=1793900700&signature=cd8b97c362861a1142f8b035d311e342e1e734bebb3893e90bdf9c1c97386f1b&req=dicvHsh8m4heWfMW1HO4za5Nd5a9tv18hNZa7O%2F20dzSYV3JPdPZOZrAHy5i%0AoRqPFuTnL6smSnoeS9U%3D%0A)

The Tag is removed from the Tags page, and its public link stops working. Its listings remain in Perchwell and in any other Tags that contain them.

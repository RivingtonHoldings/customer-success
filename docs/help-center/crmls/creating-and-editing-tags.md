# Creating and Editing Tags

# **Tags**

Tags group listings into a single, organized collection. Use them to track properties for a specific buyer, compare pricing strategies, or monitor listings over time.

Tags notify you when listings change, including price updates and status shifts. Each tag also generates a shareable public link to a customized dashboard, where clients can view all tagged listings and quickly access the external listing detail page

# **Tagging a Single Listing from Search**

Quickly tag individual listings directly on the Search page.
1. Navigate to the **Search** page
2. Click the **Tag** icon on the listing card
3. In the **Tag List** modal:
  - Select an existing tag, or
  - Enter a new tag name in the **Search or Create Tag** field, then click **Save a tag called "[tag name]"**

The listing is now added to the tag.

# **Tagging Multiple Listings from Search (Bulk Tagging)**

Use bulk tagging when you want to group several listings at once, such as properties for a specific client.
1. On the **Search** page, select the checkboxes next to the listings
2. A footer menu will appear
3. Click **Tag Selected**
4. In the **Tag List** modal, choose one or more existing tags, or create a new one
5. Close the modal

All selected listings will be added to the tag.

# **Tagging While Viewing a Single Listing**

You can also add tags from the listing detail page.
1. Open a listing from **Search** or **Universal Search**
2. On the listing page, open the actions panel on the right:
  - Hover to reveal it, or
  - Click the three-dot menu in the top right
3. Click **Add Tag**
4. Select an existing tag or create a new one

# **Managing Tags**

You can rename, delete, or configure alerts for any tag.
1. Open **Tags** from the main navigation
2. Click the **Edit (pencil)** icon next to a tag
3. In the modal, you can:
  - Rename the tag
  - Enable or disable **agent-only alerts**
  - Delete the tag

Agent-only alerts notify you of changes to listings within that tag. These alerts are not visible to clients.

# **Sharing a Tag**

Each tag includes a shareable link. This link displays all listings within that tag in one view.

This is useful when you want to send a group of listings to a client without sharing them individually.

# **Tips**
- A listing can belong to multiple tags.
- Alerts apply only to the agent who created the tag.
- Deleting a tag, will not remove the listing from any other tags it is associated with.

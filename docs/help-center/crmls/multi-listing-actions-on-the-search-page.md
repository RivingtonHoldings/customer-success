# Multi-Listing Actions on the Search Page

# Select Multiple Listings

Use the selection checkboxes to choose listings you want to manage together.

## Steps
1. Go to the **Search** page.
2. Click the checkbox next to a listing.
3. Select additional listings as needed.

Once listings are selected, the **Action Panel** appears at the bottom of the page.

> 💡Click **Select All** in the Action Panel to select all listings in the current search results.

# Use the Action Panel

The Action Panel appears when one or more listings are selected. It provides tools for managing multiple listings at once.

Available actions may include:

| **Action** | **Description** |
|---|---|
| **Create Reports** | Add selected listings to a CMA, Listing Report, or other available reports. |
| **Share via Messages** | Send listings directly to invited clients through Messages. |
| **Share** | Email listings or generate a public link to share externally. |
| **Contact Listing Agent** | Send an email to the listing agent associated with each selected listing. |
| **Tag Selected** | Add listings to one or more tags for organization. |
| **View Listings** | Open selected listings in a carousel view for quick comparison. |
| **Schedule Showing** | Schedule showings through supported ShowingTime integration. **Availibilty may vary per MLS.** |
| **Listing Presentations** | Add selected listings to a Listing Presentation. **Availibilty may vary per MLS.** |
| **Cloud CMA** | Send selected listings to Cloud CMA to create a comparative market analysis or listing presentation. **Availibilty may vary per MLS.** |

# Tip
- **View Listings** allows you to review multiple listings without opening separate listing pages.
- Some actions depend on your account permissions or connected services.
- Hidden listings will no longer appear in the current search results.

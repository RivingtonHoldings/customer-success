# Customize Your Search View

## In this article:

You will learn how to change your listing view, adjust the map, and customize the columns on your Search page so you can review listings faster.

[Embedded video](https://demo.arcade.software/2ZGJhka6MY0J6paXfupr?embed)

# Adjust your map view while you search

Tune the map so you can compare results and location context at the same time.
- From the **Filters** or **Results** page, click and drag the **3 dots** to readjust the size of the map.

- From the **Filters** or **Results** page, click the **hide map button** to hide the map.

[![image](https://downloads.intercomcdn.com/i/o/trq7czv5/2599900346/96b0aed91400c0cc87bbe2e3f8e6/Screenshot+2026-07-04+at+10_36_15%E2%80%AFAM.png)](https://downloads.intercomcdn.com/i/o/trq7czv5/2599900346/96b0aed91400c0cc87bbe2e3f8e6/Screenshot+2026-07-04+at+10_36_15%E2%80%AFAM.png?expires=1788542100&signature=e8111fc9fc90dd3ecb6f3ba1795750a90b66b57ec96fbb480e336aa0ded1e4a9&req=diUuH8B%2BnYJbX%2FMW1HO4zQuXgdSDKaZmShOy4iG5ONwR8QP2SlI6Dox8FvF5%0A8GYMs0Gabrhhof7HC2g%3D%0A)
- Switch map layers to change what you see on the map (for example, **Satellite**, **Terrain**, **Roadmap, Flood layers, or Parcel layers**).

# Customize the columns in your results table

When using either the **List** or **Expanded** view on the **Results** page, reorganize your columns to show the information that you want to see each time you run a search. You can do so from the **Columns** drop down or by dragging and dropping the columns on the results page.

Steps to reorganize columns on the **Columns** drop down:

[![image](https://downloads.intercomcdn.com/i/o/trq7czv5/2599904674/6ec1bd50fea07d314b8244f945be/Screenshot+2026-07-04+at+9_55_21%E2%80%AFAM.png)](https://downloads.intercomcdn.com/i/o/trq7czv5/2599904674/6ec1bd50fea07d314b8244f945be/Screenshot+2026-07-04+at+9_55_21%E2%80%AFAM.png?expires=1788542100&signature=dacb4abbc511f720b8f85a4f2a40018b516785682f9f192476526f7c63508810&req=diUuH8B%2BmYdYXfMW1HO4zU0nkhZe3Nm%2FeatU28nqZKVAnsD8uHZPPEE0YWxN%0AIkzQZ3BsiKX0E5vuGak%3D%0A)
1. Click on **Results** to view the listings that match the filters.
2. Click the **Columns** drop down.
3. Drag and drop columns to change the order by clicking the **6 dots** and dragging the column.
4. Select or deselect the checkboxes next to the columns you want to add or remove from the view.
5. Click **Save** and name the template. You can select the **star** to save it as the default column view.

Steps to reorganize columns by reordering the columns on the results page:

[![image](https://downloads.intercomcdn.com/i/o/trq7czv5/2599904860/b8f94473261ca5a6ddba5dc6cea2/Screenshot+2026-07-04+at+9_55_41%E2%80%AFAM.png)](https://downloads.intercomcdn.com/i/o/trq7czv5/2599904860/b8f94473261ca5a6ddba5dc6cea2/Screenshot+2026-07-04+at+9_55_41%E2%80%AFAM.png?expires=1788542100&signature=f7766c0c8e15ca58ebf43388b3414420343ce059a6ad0f0f6bd07ce3ccd34cc0&req=diUuH8B%2BmYlZWfMW1HO4zcnygdt9jiPFCcMqiUzxucnCTJ%2FgZ0C5g7jOYyJM%0AValYha5nJB64RMhEvgA%3D%0A)
1. Click on **Results** to view the listings that match the filters.
2. Click the columns and hold down the mouse.
3. Drag the column to create the desired order.
4. Click the **Columns** drop down.
5. Drag and drop columns to change the order by clicking the 6 dots and dragging the column.
6. Select or deselect the checkboxes next to the columns you want to add or remove from the view.
7. Click **Save** and name the template. You can select the **star** to save it as the default column view.

Once you're done customizing your search results view, you can save your column layout as a template for future searches.

## Steps:
1. Click the Columns drop down
2. Click **Save New**
3. Name your Template
4. View all saved templates, in the Template view.

# Saving Listings with Tags

# How to Save a Listings with Tags

[Embedded video](https://www.loom.com/embed/76d49beef26d438480dda77402cea7c9)

### 1. Access the Tagging Tool
1. Start on the Search page.
2. Find the tag icon next to any listing.

### 2. Tag a Single Listing
1. Click the tag icon on a listing.
2. Select an existing tag or type a name to create a new one.
3. Click Save Tag.

### 3. View Listings in a Tag
1. Click View Tag Properties in the tag menu.
2. Use the search bar to quickly locate your tag.

### 4. Tag Multiple Listings
1. Check the box next to each listing you want to tag.
2. In the action bar at the bottom, click Tag Selected.
3. Choose a tag or create a new one and save.

### 5. Tag from the Listing Detail Page
1. Open the listing detail page.
2. Click the three dots in the upper corner.
3. Select Add to Tag.
4. Choose or create a tag and save.

## Tips and Best Practices
- Create simple and consistent tag names to stay organized.
- Review your tags regularly to keep your workspace clean.
- Use tags to group listings for clients, market research, or personal tracking.

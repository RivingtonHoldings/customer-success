# Find the Perchwell Report That Replaces Each Matrix Report

Use this article to find the Perchwell report that replaces a Matrix report and create it from your search results.

# Matrix reports and the Perchwell reports that replace them

Perchwell reports replace every Matrix report in this table except the four in the last row. This table lists each Matrix report with the Perchwell report that replaces it.

| Matrix report | Perchwell report | Good to know |
|---|---|---|
| Agent Single Line | Search results Print, in List view | Prints your column template. Search criteria do not print. |
| Agent Thumbnail / Buyer Thumbnail | Listing Report | Turn agent information on or off. |
| Agent Full / Buyer Full | Full Report, agent version or client version | The client version adds your contact information and space for client notes. |
| Agent Summary / Buyer Summary / Synopsis | One Pager | One listing per page, with a QR (quick response) code. |
| Flyer | Show Sheet | Adds options for floor plan and map. |
| Quick CMA | Quick CMA (Comparative Market Analysis) | Fits up to 9 fields in portrait and 11 in landscape. Larger Font fits 3 fewer fields. |
| 3-Up | Listing Report | Shows similar information, laid out horizontally. |
| 1004MC Summary / Detail | 1004MC Market Conditions Addendum | Covers up to 500 listings. |
| Multi Map | Itinerary, or Driving Directions in the Actions menu | The Itinerary report numbers your listings in order, starting with 1. To get driving directions, select up to 9 listings, click Actions, and select Driving Directions. Google Maps opens in a new tab with a route that includes each listing. |
| Market Analysis / MLS Statistics / Area Market Survey | Search Analytics or Market Analytics | Shows charts rather than one-page tables. |
| Photo Single Line, Input Order, Hotsheet print, President's Sales Club | Not in Perchwell | No Perchwell report matches these. To print a Hot Sheet, print its results from the results list. |

# Create a Perchwell report from a search

Create any Perchwell report from your search results on the Search page. Every Perchwell report starts from a search.

## Steps:
1. Click Search in the top navigation
2. Run a search or open a saved search
3. Select the listings for the report
4. Click Actions
5. Select Create a Report
6. Select the report

The Customize Report step opens for the report you chose.

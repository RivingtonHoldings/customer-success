# Create a Detailed Report

# When to use a Detailed Report

Use a Detailed Report when you need a complete listing packet with full details and all available photos.
- Share a full property overview with a client
- Prep materials for showings or a property review
- Send detailed listing information to an agent or colleague
- Print a comprehensive listing packet

# Detailed Report creation

Choose the starting point that matches how you selected your listings.

## Start from Search (most common)

Use this option when you are selecting multiple listings from your search results.

### Steps:
1. Open **Search page**
2. Switch to the listing results by clicking **Search**
3. Select the checkboxes next to the listings you want to include
4. Click **Actions**
5. Select **Create a Report**
6. Choose **Quick CMA**

## Start from Listing Detail Page

Use this option when you want a report for one specific listing.

### Steps:
1. Open a listing from **Search** or **Universal Search**
2. Open the actions panel on the right
  - Hover near the right edge of the page, or
  - Click the **three-dot menu** in the top right
3. Click **Add to Report**
4. Select **Detailed Report**

## Start from Tags

Use this option when your listings are already grouped in a tag.

### Steps:
1. Open **Tags**
2. Open the tag that contains your listings
3. Click **Create Report**
4. Select **Detailed Report**

By default, the report includes all listings in the tag. Reorder listings or remove listings after the report editor opens.

## Detailed Report customization

After you select **Detailed Report**, review the report settings and choose what recipients will see.

## Choose how listing links open

Set what happens when someone clicks a listing link in the report.
- Select **Open in Perchwell**
- Select **Open externally with your branding**

## Select the fields to display

Choose which listing details appear in the report:
- Include your contact information
- Include the exact address
- Include Days on Market (DOM)
- Include open house information
- Include list date
- Include cross streets
- Include neighborhood
- Include internal information
- Include a large map

Unit numbers will be included when applicable.

**💡 Click Include Exact Address to let recipients open the client-facing Listing Detail Page directly from the report.**

## Reorder or remove listings

Adjust the listings included in the report before you share it.
- Drag and drop listings to reorder them
- Click the **X** to remove a listing

When finished, click **Next**.

# Detailed Report sharing

After you review your settings, choose how you want to distribute the report.

## Email

Send the report directly to an email address.

### Steps:
1. Select **Email**
2. Enter the recipient’s email address
3. Update the subject line
4. Review the message body and make edits as needed
5. Click **Email Report**

## Download

Generate a PDF you can save or share.

### Steps:
1. Select **Download**
2. Wait for the PDF to generate
3. Save the file to your device

## Print

Print a paper copy or save as a PDF from your browser.

### Steps:
1. Select **Print**
2. In your browser’s print dialog, choose your printer and settings
3. Click **Print**

## Tips
- Click **Previous** to return to earlier steps and adjust settings.
- Add more listings by creating a new report.
- Find saved reports in your **Report Library**.
- Search for a report using the recipient’s email address.

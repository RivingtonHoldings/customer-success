# Set Up Email Alerts for Saved Searches

[Embedded video](https://www.loom.com/embed/e5c96277ed3b4e09b1047fbe4549fc9e)

# Search Settings access

Alert settings live in **Search Settings** for each saved search.

### Steps:
1. Go to **Search**
2. Click **My Searches **in the top left of the Search window
3. Find the saved search you want to update
4. Click the **Search Settings** icon

The search settings pop-up opens.

# Alert settings

Set your alert schedule, then save your changes.

### Steps:
1. In the search settings, set up your **Notifications** and **Frequency**.
2. Select an alert **Frequency**
3. Select the alert types you want to receive
4. Select your recipient option
5. Click **Update**

# Alert frequency options

Pick how often this saved search sends an alert email. Daily, weekly, and monthly alerts go out in a **Morning** or **Evening** window in your MLS time zone.

| **Frequency** | **What to choose** | **When it sends** |
|---|---|---|
| **Immediately** | Nothing else | Checks every hour and sends when something qualifies |
| **Daily** | **Morning** or **Evening** | Once a day in the window you pick |
| **Weekly** | A day of the week, plus **Morning** or **Evening** | Once a week on that day |
| **Monthly** | A day of the month from 1 to 28, plus **Morning** or **Evening** | Once a month on that day |

Weekly or monthly alerts work well for clients who want a regular market update without a daily email.

# Alert types

Select one or more alert types. Each email includes only listings that match the saved search and had that activity since the last alert.
- **New Listing**: a listing that newly matches the search
- **Status Change**: a matching listing changed status
- **Price Drop**: a matching listing lowered its price
- **New Open House**: a matching listing added an open house that is still upcoming

# Alert recipients

Select who should receive the alerts for this saved search.

| **Option** | **Description** |
|---|---|
| **My Email Only** | Send alerts only to you. |
| **My Email + Contacts** | Send alerts to you and the contacts added to the saved search. |
| **Contacts Only** | Send alerts only to the contacts added to the saved search. |

Contacts must be added to the saved search to receive alerts.

# Contact alerts

Add clients to have access to the saved search.

### Steps:
1. Open **Search Settings** for the saved search
2. Click **Contacts**
3. Select an existing contact or create a new contact
4. Toggle on **Allow added contacts to see and edit this search**
5. Save your changes

# Alert email contents

Each alert email includes the details you need to review matches quickly.
- The saved search name, with a link to open the search
- A preview of matching listings
- Links to open each listing detail page

## Things to Know
- Alerts only send when there is something to report, which means your clients do not receive empty emails on quiet days.
- Morning alerts send around 8:00 AM and Evening alerts around 8:00 PM in your MLS time zone.
- A status change or price drop that pushes a listing outside your search filters does not trigger an alert.
- Monthly alerts run on days 1 through 28 only, so every month has the selected day.
- Alerts cover activity after you save the settings. Listings that already matched are not re-sent.
- Add contacts before selecting a contact recipient option.
- Contacts without an account can still open the listing links in the email.
- While the new alert options roll out, some members may receive two copies of an alert email for the same saved search. Contact support if that happens.

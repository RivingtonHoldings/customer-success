# Create and Share Full Reports

# When to use a Full Report

Use a Full Report when you want to print a copy of the entire Listing Detail Page.
- Share detailed listing information with a client
- Prep materials for showings or listing presentations
- Send a full property packet to an agent or colleague
- Print property documentation for an in-person meeting

[Embedded video](https://demo.arcade.software/IDl2eNP0YLOorXpgPtaS?embed)

# Full Report creation on the Listing Detail Page

Use this option when you need a Full Report for one listing.

### Steps:
1. Open a listing from **Search**, or find it using **Universal Search**
2. On the **Listing Detail Page**, click the** actions **button
3. Select **Full Report**
4. Choose a report type
  - Select **Client Version** to include your contact information and space for client notes
  - Select **Agent Version** to include agent-only information like showing instructions
5. Click **Create**

The report opens in a print preview window.
- Print the report
- Save the report as a PDF

# Full Report creation on the Search page

Use this option when you need a Full Report for multiple listings.

### Steps:
1. Open **Search**
2. Select the checkboxes next to the listings you want to include
3. In the footer action bar, click **Create Report**
4. Select **Full Report**
5. Choose a **Report Type**
  - Select **Client version**
  - Select **Agent version**
6. Click **Next**

## Tips
- Click **Previous** to adjust the listings in your report.
- Add more listings by creating a new report.
- Full reports are a great way to print a the full Listing Detail Page.

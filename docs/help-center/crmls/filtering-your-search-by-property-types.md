# Filtering your Search by Property Types

# Access the Property Type Filter

## Steps
1. Go to the **Search** page.
2. Locate the **Property Type** filter in the filter panel.
3. Select one or more property types.

Your search results will update automatically based on your selections.

# Understanding Property Types

From the **Search** page, choose one or more property types to narrow your results.

Available property types may include:

| **Property Type** | **Definition** |
|---|---|
| **Residential** | Single-family homes, condominiums, townhomes, and other owner-occupied housing types. |
| **Residential Lease** | Residential properties available for rent. |
| **Commercial Sale** | Commercial properties available for purchase, such as office, retail, or industrial spaces. |
| **Commercial Lease** | Commercial properties available for lease. |
| **Land** | Vacant lots or undeveloped parcels. |
| **Residential Income** | Multi-unit residential properties intended for rental income. |
| **Manufactured in Park** | Manufactured homes located within a designated park community. |
| **Business Opportunities** | Properties categorized as development or investment opportunities, depending on MLS classification. |

# Refine Property Type Selections

For certain property types, you can apply additional filters.

When selecting **Residential**, **Commercial**, or **Land**, you may be able to refine by:
- Property subtype
- Structure type
- Common interest

Select the applicable options to further narrow your results.

# Tips
- Sales and rentals cannot be selected simultaneously within the same search.
  - To review sales and rentals together, add listings to the same tag and view them from the **Tags** page.
- When refining property types, you can choose whether to include listings without a specified subtype.

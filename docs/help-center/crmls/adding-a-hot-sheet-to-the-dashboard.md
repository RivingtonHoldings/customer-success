# Adding a Hot Sheet to the Dashboard

[Embedded video](https://www.loom.com/embed/9098418b98724b249bb32cdacf74640b)

# **Types of Hot Sheets**

Perchwell's Dashboard allows you to create custom **Hot Sheets**, enabling you to track listing activity over time. You can create two types of Hot Sheets.
1. **Saved Search Hot Sheets**: Show the listing activity over different time periods for listings in a Saved Search.
2. **Quick Hot Sheets**: Show the listing activity over different time periods for listings in an MLS that can be filtered by property type or location, depending on the MLS.

# **Step 1: Adding a New Hot Sheet to the Dashboard**
1. Click **‘Dashboard’** in the navigation menu at the top of the webpage.
2. Select **‘Manage Widgets’** to access your dashboard customization options.
3. Click **‘Add Hot Sheet’** to create a new Hot Sheet.
4. Navigate to the new **Hot Sheet Widget** to set up the criteria.

# **Step 2: Creating Different Types of Hot Sheets**

## **Option #1: Creating a Quick Hot Sheet Based on Property Types**

Create a quick hot sheet to track changes based on specific property types.
1. Open the **Hot Sheet Widget** and select **‘New Hot Sheet.’**
2. Enter a **name** for your Hot Sheet.
3. Choose the **Property Types** you’d like to monitor from the drop-down menu.
4. Select the **Locations** you’d like to include. You can select areas by County, City, MLS area, or all three.
5. Set the **time frame** you’d like to monitor.
6. Select or deselect the **statuses** you want to track.
7. Confirm your changes to save the Hot Sheet.

## **Option #2: Creating a Hot Sheet Based on a Saved Search**

Easily stay up to date on the market by setting up hot sheets to stay up to date on new deals, price changes, and status updates.
1. Open the **Hot Sheet Widget** and select **‘From Saved Search.’**
2. Enter a **name** for your Hot Sheet.
3. Choose the **Saved Search** you want to monitor from the drop-down menu.
4. Set the **time frame** you’d like to monitor.
5. Select or deselect the **statuses** (e.g., Active, Pending, Sold) you want to track.
6. Confirm your changes to save the Hot Sheet.

# **Tips & Best Practices**
1. **Maximum Hot Sheets**: Add up to **5 Hot Sheets** to your dashboard for real-time monitoring.
2. **Time Frame Limit**: You can monitor properties for up to **998 days**.
3. **Saved Searches for Precision**: Create **Saved Searches** with specific criteria before building Hot Sheets for efficient property tracking.

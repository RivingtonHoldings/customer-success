# Tags Page Overview

# **Navigate to Tags**

Access all tag tools from the **Tags** page.

## Steps
1. Click **Tags** in the top navigation bar
2. Use tags to organize listings for clients, reports, or internal tracking

With tags, you can:
- Create and manage listings that you have sold.
- Customize alert notifications on selected listings.
- Share listings with clients.
- Delete tags when they are no longer needed.

# **Create Tags**

You can tag listings from multiple areas in Perchwell.

## Common Ways to Create Tags
1. From **Search**, click the **tag icon** next to a listing.
2. From **Search**, select multiple listings and click **Tag selected** in the action panel.
3. From a **Listing Detail Page**, click **Tag** in the action panel.

# **Edit Tags and Manage Alerts**

Update tag names and control alert notifications directly from the **Tags** page.
- Edit tag names as client needs change.
- Choose which listing updates trigger alerts.
- Turn alerts on or off at any time

# **Share Tags with Clients**

Share a group of listings using one public link.

## Steps
1. Go to the **Tags** page.
2. Use the search bar to find the tag folder.
3. Click the **link icon** to generate a shareable link.
4. Copy and share the link by email, text, or on your website.

# **Delete Tags**

Remove tags once listings are no longer relevant or a deal has closed.

# **Common Use Cases for Tags**
- Share open houses or active listings using one public link.
- Track client preferences by tagging listings per buyer.
- Monitor price changes in specific neighborhoods.
- Organize listings by deal stage, such as Under Contract.

# Review Saved Searches Moved from Matrix

Use this article to find your saved searches moved from Matrix and their contacts, review and fix their filters, remove the [From Matrix: Unreviewed] prefix, and turn their alerts back on.

# Find saved searches moved from Matrix

Click Saved Searches, or the name of the open saved search, in the upper left of the Search page to open the My Searches window. Each saved search moved from Matrix starts with [From Matrix: Unreviewed] in its name.

Saved searches moved in a one-time transfer at the start of your Perchwell member training. A saved search created in Matrix after the transfer did not move, so recreate it in Perchwell.

# Find the contacts linked to saved searches moved from Matrix

Saved searches moved from Matrix stay linked to the contacts they had in Matrix. Find those contacts in two places:
- Contacts column: Lists each saved search's contacts in the My Searches window, which opens from Saved Searches on the Search page.
- Shared Searches tab: Lists every saved search linked to one contact, on the left side of that contact's page.

# Add a missing contact to a saved search moved from Matrix

Add a contact to a saved search in the saved search's Edit Search window when the link between them did not move.

## Steps:
1. Click Saved Searches, or the name of the open saved search, in the upper left of the Search page
2. Click the pencil icon next to the saved search
3. Select the checkbox next to the contact in the Contacts dropdown
4. Click Update

The contact appears in the saved search's Contacts column in the My Searches window. [Manage Your Saved Searches](https://support.perchwell.com/crmls/en/articles/18234059-manage-your-saved-searches) explains sharing a saved search with a contact.

# Review and update a saved search moved from Matrix

Check the filters of each saved search moved from Matrix on the Search page to confirm it finds the listings you expect. Save any changes to the same search.

## Steps:
1. Click Saved Searches, or the name of the open saved search, in the upper left of the Search page
2. Click the name of a saved search that starts with [From Matrix: Unreviewed]
3. Click Filters in the upper right of the Search page
4. Compare Applied Filters with what the search is meant to find
5. Add any filter the search is missing
6. Click Save
7. Click Update Current in the Save Search window

The saved search keeps your changes, and its name still starts with [From Matrix: Unreviewed] until you remove the prefix.

# Remove the prefix and turn on alerts for a saved search moved from Matrix

A saved search with alerts turned on replaces Matrix Auto email. Every saved search moved from Matrix has its alerts turned off, which means no one receives alert emails for it until you turn them on. After you review a saved search, delete [From Matrix: Unreviewed] from its name and turn on its alerts in the Edit Search window.

## Steps:
1. Click Saved Searches, or the name of the open saved search, in the upper left of the Search page
2. Click the pencil icon next to the saved search to open the Edit Search window
3. Delete [From Matrix: Unreviewed] from the Name this search field
4. Turn on the Alerts toggle
5. If you want contacts to receive the alerts, select an option from the Recipient dropdown
6. Click Update

A green "Your saved search has been updated." message appears in the lower right. The saved search's name no longer starts with the prefix, and its alerts are on. Recipient controls who receives the alerts, so check it before you click Update. [Set Up Email Alerts for Saved Searches](https://support.perchwell.com/crmls/en/articles/18234126-set-up-email-alerts-for-saved-searches) explains how often alerts send and each Recipient option.

To turn on alerts without changing the name, click the bell icon next to the saved search in the My Searches window. The icon turns green.

Matrix email alerts keep sending after the move, so turn them off in Matrix. [Review Your Data Moved from Matrix](https://support.perchwell.com/crmls/en/articles/18247287-review-your-data-moved-from-matrix) explains what else moved.

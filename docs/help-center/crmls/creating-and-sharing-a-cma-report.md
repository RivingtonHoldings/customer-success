# Creating and Sharing a CMA Report

[Embedded video](https://www.loom.com/embed/9f3842667c864ad7981ea4271f242e36)

## Select and Organize Listings
1. Start on the Search page and apply your filters.
2. Check the box next to each listing you want to include.
3. To select all visible listings, use the option in the action window at the bottom.
4. Click Create Report and select the CMA report type.
5. Rearrange the listing order by dragging them into the sequence you prefer.
6. Add a subject property or additional listings from any tags you have created.

## Customize Your CMA
1. Add a title for your report such as a client name, neighborhood, or property type.
2. Include an optional subtitle if you want to add more context.
3. Choose your page format. Portrait offers fewer field options while Landscape provides more room for data.
4. Toggle fields on or off to control what appears in the report. Your last selections are saved for next time.
5. Select how report links open. By default, links open externally with your brokerage branding.
6. Turn on Exact Address if you want clients to click directly into the client facing listing detail page.

## Share and Review Your Report
1. Click Next to select recipients.
2. Add a subject line and message if sharing by email.
3. Send your report by email, download it as a PDF, or print it for an in person meeting.
4. Review the final report to confirm accuracy.
5. Clients can click on any address to view more listing details.

## Tips and Best Practices
- Apply filters carefully so your CMA includes the right listings.
- Review the title and subtitle before sharing.
- Save frequently used filters for faster workflow.
- Explore field toggles to speed up future customization.

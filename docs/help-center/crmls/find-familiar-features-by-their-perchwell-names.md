# Find Familiar Features by Their Perchwell Names

Use this article to look up what a feature you used in Matrix is called in Perchwell. [What Changed When You Moved to Perchwell](https://support.perchwell.com/crmls/en/articles/18247297-what-changed-when-you-moved-to-perchwell) explains how those workflows have changed.

# Perchwell names for search filters and tools

This table matches search filters and tools from Matrix to their Perchwell names.

| Matrix term | Perchwell name |
|---|---|
| Power Bar | Universal Search Bar, the Search field in the top navigation |
| Search Criteria | Search filters, set on the Filters tab of the Search page |
| Narrow / Discard | Keep and Hide, options for the listings you select in your search results |
| Display | Column template, in the Columns menu above your search results |

For more information:
- [Universal Search Bar](https://support.perchwell.com/crmls/en/articles/18234136-universal-search-bar) explains how to find a listing, agent, or contact from any page.
- [Create a Search with Filters](https://support.perchwell.com/crmls/en/articles/18233998-create-a-search-with-filters) covers setting search filters.
- [Customize Your Search Results View](https://support.perchwell.com/crmls/en/articles/18234037-customize-your-search-results-view) explains how to create and apply column templates.

# Perchwell names for listing tools

This table matches listing entry and listing detail tools from Matrix to their Perchwell names.

| Matrix term | Perchwell name |
|---|---|
| Add/Edit (listing input) | Not in Perchwell. Keep entering and editing listings in Matrix. |
| Supplements | Documents, a tab on the Listing Detail Page |
| External Links | Integrations panel, on the right side of the Dashboard |
| Township | Community, a section of the Filters tab with the Subdivision name and Subdivision name other fields |

[Access Integrations from the Dashboard or a Listing](https://support.perchwell.com/crmls/en/articles/18247068-access-integrations-from-the-dashboard-or-a-listing) lists the integrations that open from the Dashboard. [Listing Field Changes in Perchwell](https://support.perchwell.com/crmls/en/articles/18247269-listing-field-changes-in-perchwell) explains the Community field.

# Perchwell names for Dashboard, Hot Sheet, and Analytics features

This table matches market activity and reporting features from Matrix to their Perchwell names.

| Matrix term | Perchwell name |
|---|---|
| Market Watch | Hot Sheets on the Dashboard |
| Stats tab | Market Analytics, the Analytics tab; Search Analytics, within a search; or Market Activity, an Analytics report |

[Add a Hot Sheet to the Dashboard](https://support.perchwell.com/crmls/en/articles/18232986-add-a-hot-sheet-to-the-dashboard) explains how to create a Hot Sheet. [Analytics Page Overview](https://support.perchwell.com/crmls/en/articles/18234722-analytics-page-overview) covers the Analytics reports.

# Perchwell names for client collaboration and mobile tools

This table matches client collaboration and mobile features from Matrix to their Perchwell names.

| Matrix term | Perchwell name |
|---|---|
| Auto email | Saved search with client alerts turned on |
| Carts | Tags |
| OneHome | Perchwell client account, for an invited client |
| MLS Touch | Perchwell mobile app |

- [Accept Your Agent's Perchwell Invitation](https://support.perchwell.com/crmls/en/articles/18231917-accept-your-agent-s-perchwell-invitation) walks an invited client through getting started.

# Using the Map on the Search Page

# Navigating to the Map on the Search Page

You can view the interactive map directly on the **Search** page. The Map View displays listings based on your current search criteria.

Each listing appears according to its geolocation.

You can adjust how the map is displayed:
- Select **Hide Map** to increase screen space for listings.
- Choose different layout sizes such as full, ¾, ½, or ¼ view.

> 💡 Listings update automatically as filters or map boundaries change.

# Zoom and Navigate the Map

Use the + and - icons to zoom in and out of the map. You can also use finger gestures on a trackpad or mouse. As you zoom in or out:
- **Cluster markers** adjust automatically.
- Each cluster marker displays the number of listings within that area that match your search criteria.

Zooming in will break larger clusters into smaller groups or individual listings.

Zooming out will combine listings into larger clusters.

# Select Areas on the Map

Click directly on a location on the map to refine your search.
- The map will zoom into the selected area.
- The selected location is automatically added to your search.
- You can click additional areas to expand your search.

Results update immediately based on selected areas.

# View Listings Within a Cluster

Click a cluster marker to view listings in that area.
- A tile list of matching listings will appear.
- Selecting a listing tile opens the listing detail page in a new browser tab.

# Map Layers

You can enable additional map layers for geographic context:
- **Roadmap**
- **Satellite**
- **Terrain**

# Tip
- Map results reflect your active search filters.
- Cluster markers represent only listings that match your criteria.
- Zooming changes how listings are grouped.
- Clicking a listing opens it in a new tab.

# Realist Integration

[![image](https://downloads.intercomcdn.com/i/o/trq7czv5/1564139942/437011427cd3dc951c21c2edf201/Group+409.png)](https://downloads.intercomcdn.com/i/o/trq7czv5/1564139942/437011427cd3dc951c21c2edf201/Group+409.png?expires=1788542100&signature=f0f8129f9c7a756582d4be51ac3545e856ecdcd4ca8d76fb10e42e72217d177b&req=dSUhEsh9lIhbW%2FMW1HO4zeiFtB729ytoEcADpLjJSy%2Bb0JzEIfkTV08SzAzU%0A6crzwjSctUyAM7MIrYw%3D%0A)

## **How to Use the Realist Integration**
1. Navigate to any **Property Detail Page** in Perchwell
2. Locate the **Realist icon** in the right-hand sidebar
3. Click **"Open in Realist"**
4. A new tab will open with detailed Realist property information
5. Use this data to verify ownership, view parcel history, and cross-check property records with what’s shown in Perchwell

## **Tip:**

Use Realist as part of your pricing or listing prep workflow. It’s especially useful for uncovering property history, ownership changes, and lot-level data you may not see in the MLS listing.

## **Things to Know**
1. You must be logged into **RECore** to access Realist data
2. This feature is currently available only for **CRMLS agents**
3. Realist will open in a new browser tab so you can review the full report while keeping Perchwell open

# Access Tag Alert Settings

Tag Alerts are configured within each tag’s settings.

## Steps
1. Go to the **Tags** page.
2. Click the bar labeled **Click to view and filter tags**.
3. Locate the tag you want to manage.
4. Click the **Edit (pencil)** icon next to the tag.

The **Edit Tag** window will open.

# Configure Tag Alerts

Use the alert settings to control which updates trigger notifications.

## Steps
1. In the **Edit Tag** window, toggle **Get alerts for this tag** on or off.
2. Select the updates you want to monitor:
  - **Price Changes**
  - **Status Changes**
  - **New Listings**
3. Click **Save** to apply your changes.

Alerts will be sent to your email when selected events occur.

# Quickly Toggle Alerts from the Tags Page

You can also enable or disable alerts directly from the Tags page.

## Steps
1. Go to the **Tags** page.
2. Click the bar labeled **Click to view and filter tags**.
3. Locate the tag you want to adjust.
4. Click the **bell icon** to turn alerts on or off.

This allows you to update alerts without opening the edit window.

# What Tag Alert Emails Include

When a tagged listing changes, Perchwell sends an email alert to the agent.

The email includes:
- A **subject line** that displays the **listing address and the type of update** (for example, a status change or price change).
- A **link to the listing detail page.**
- A **link to the tag folder** where the listing is saved.
- A **summary of the listing update.**

# Tips
- Tag Alerts notify **agents only** about changes to listings already saved in a tag.
- Alerts are **enabled by default** when a new tag is created.
- Clients do **not** receive Tag Alerts.
- To notify clients about new listings automatically, use a **Saved Search**.
- To share curated listings manually, send a **tag link**.

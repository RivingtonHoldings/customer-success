# The Days Active on Market Widget

# **Add or Manage the Widget**

The **Days Active in MLS** widget appears on the Dashboard by default.

You can:
- Drag and drop the widget to change its position.
- Click **Manage Widgets** to show or hide widgets. # **Understand the Data**

The chart displays:
- **Median days active on market (DOM).**
- One data point per month.
- A rolling three-year timeframe.

Hover over a data point to view the median value for that specific month.

The data updates automatically as MLS data changes.

# **Definitions**
- **Days Active on the Market (DOM):** The number of days a listing remains on the market before being sold or going off market.
- **Cumulative Days Active on the Market (CDOM):** The total number of days a listing has been on the market across multiple listing periods, if applicable.

The widget displays median values for the selected timeframe.

# **Explore the Data Further**

To analyze listings behind a specific month’s data:
1. Go to the **Search** page.
2. Apply filters for:
  - Status
  - Listing Activity
  - Date range
3. Open the **Analytics** tab.
4. Create a chart using the **Days on Market** chart in the Location category.

This allows you to review the listings contributing to the Dashboard metric.

# **Tips**
- Widget data cannot be edited manually.
- This widget cannot be removed from the Dashboard page.

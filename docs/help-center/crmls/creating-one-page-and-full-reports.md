# Creating One Page and Full Reports

[Embedded video](https://www.loom.com/embed/3e9f412b4af24643be7cd87178bf82d0)

## Step 1: Access and Prepare the Listing
1. Navigate to the listing detail page.
2. Click the three dots at the top of the page to open the action menu.
3. Before generating a report, collapse any sections you want to hide such as agent remarks or internal fields. This helps you control what appears in the final report.

## Step 2: Create Your Report

## One Page Report
1. In the action menu, select One Page Report.
2. Choose Agent View or Client View.
  - Agent View includes full listing information.
  - Client View hides listing only details.
3. Click Create to open the report in a new tab.

## Full Page Report
1. Open the action window at the bottom of the page.
2. Select Full Report.
3. Follow the same steps you used for the one page report.

## Step 3: Save, Share, and Understand Your Report
1. After the report opens, you can download, print, or save it as a PDF.
2. One page reports provide a concise summary for quick client updates and include a QR code that links to the full listing detail page.
3. Full page reports present more detailed information and are ideal for printed packets or property overviews.

## Tips and Best Practices
- Always double check whether you selected Agent View or Client View, especially before sharing with clients.
- Collapse any sections you do not want included to create a clean and professional report.
- Use the QR code in one page reports to make it easy for clients to view full listing details on their phone.

# Create Email Templates

# In this article:

You will learn how to create and save email templates in Perchwell so you can quickly reuse approved messaging when you invite clients, send reports, or contact listing agents.

# What email templates are used for

Email templates help you send consistent messages without rewriting the same email each time.

## Create templates to:
- Invite clients to Perchwell
- Send report emails (CMA, itinerary, or listing)
- Email a listing agent

# Email template creation

Create templates from **Settings** so they are ready to use when you send emails.

### Steps:
1. Open **Settings**
2. Click **Email Copy Templates**
3. In **Invited Clients**, click **+ Add Template**
4. Enter a template name and write your message in the body field
5. Click **Save**

After you save a template, it appears as an option the next time you invite a client.

# Example templates for inviting clients

Use these examples as a starting point, then update the wording to match your tone and process.

## First message template (initial invite)

> **💡 Great for when you're inviting clients to Perchwell for the first time.**

*→ Hey, [name]!*
​

*This is Perchwell, the tool I'll be using to help you find your perfect home! I will send a follow-up email shortly to help you get started. For now, please create your password using the link provided here, either in a mobile or desktop web browser.*

## Tips
- Create separate templates for **Invited Clients**, **Contact Agent** emails, and report emails so you can choose the right message for each workflow.

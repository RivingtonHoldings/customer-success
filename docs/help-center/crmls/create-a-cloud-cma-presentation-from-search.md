# Create a Cloud CMA Presentation from Search

# **Create a CloudCMA Presentation from Search**

You can send selected listings from Search directly into CloudCMA.

## Steps
1. Navigate to **Search**
2. Select one or more listings using the checkbox
3. In the action panel, click **CloudCMA**
4. CloudCMA opens with the selected listings preloaded

No manual re-entry of listing details is required.

# **How It Works**
- Listings selected in Perchwell are transferred directly into CloudCMA
- A new CloudCMA Listing Presentation is created
- You can continue building and customizing your presentation within CloudCMA

This integration allows you to move from property selection to presentation building in one workflow.

# **Access Requirements**

This feature is available to users who already have CloudCMA access.

If CloudCMA is not available:
- You may be prompted to log in
- You may need to contact your MLS or administrator for access

# Create One Page Reports

# When to use a One Page Report

Use a One Page Report when you need a quick, client-ready listing summary.
- Share key property details during a showing
- Send a simple listing overview to a client
- Print a one-page handout for an in-person meeting
- Give clients a fast way to open the full listing with a QR code

# One Page Report creation (Listing Detail Page)

Use this option when you need a One Page Report for one listing.

### Steps:
1. Open a listing from **Search**, or find it using **Universal Search**
2. On the **Listing Detail Page**, click the **actions button**
3. Select **One Page Report**
4. Choose a report type
  - Select **Client Version** to include your contact information and space for client notes
  - Select **Agent Version** to include agent-only details like showing instructions
5. Click **Create**

The One Page Report opens in a new tab to:
- Download the report
- Print the report
- Share the report

## QR code use

Each One Page Report includes a QR code that links to the client-facing **Listing Detail Page**.
- Scan the QR code from a mobile device
- Open the full listing details

## One Page Report creation (Search)

Use this option when you need a One Page Report for multiple listings.

### Steps:
1. Open **Search**
2. Select the checkboxes next to the listings you want to include
3. In the footer action bar, click **One Page Report**
4. Choose a **Report Type**
  - Select **Client version**
  - Select **Agent version**
5. Click **Next**

## Tips
- Click **Previous** to adjust the listings in your report.
- Add more listings by creating a new report.
- Find saved reports in your **Report Library**.
- Search for a report using the recipient’s email address.

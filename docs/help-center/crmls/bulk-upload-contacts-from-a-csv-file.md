# Bulk Upload Contacts from a CSV File

Use this article to import a list of contacts into Perchwell from a CSV (comma-separated values) file, fix any import errors, and invite the contacts you add.

# When to bulk upload contacts

Bulk upload contacts when you have a list of contacts to add to Perchwell at once, such as:
- A contact list exported from your CRM (customer relationship management system)
- A client list from a spreadsheet or another outside source

Members who joined Perchwell from a legacy platform may already have their contacts on the Contacts page, so check there before you upload them.

# Open the Bulk Upload window on the Contacts page

To open the Bulk Upload window, click Upload in the upper right of the Contacts page. Bulk upload works in Perchwell in a web browser, not in the Perchwell mobile app.

# Download and fill in the CSV template

Download the CSV template from the Bulk Upload window, then add your contacts to it.

## Steps:
1. Click Download CSV Template
2. Open the downloaded template in a spreadsheet program
3. Enter your contacts in the template
4. Save the file in CSV format

Your CSV file is ready to upload in the Bulk Upload window.

## CSV template requirements for bulk upload

Fill in the CSV template to these requirements so the bulk upload finishes without errors:
- Required fields: Include a First Name, Last Name, and Email Address for each contact.
- Optional fields: Add a Phone and up to five additional emails in Additional Email 1 through Additional Email 5.
- Unique email addresses: Give each contact a different email address. Duplicate emails are not allowed.
- Column headers: Keep the template's column headers exactly as they are. Do not rename or reorder them.
- Contacts per file: Upload up to 100 contacts per file. To add more than 100, split them into separate CSV files and upload each one.
- File size: Upload a file of 5 MB or less.

> **Tip:** When exporting a CSV file from Apple Numbers, deselect "Include table names" to prevent an extra row from appearing in the exported file.

# Upload the CSV file and review the import summary

Upload your completed CSV file in the Bulk Upload window, then check the import summary before you finish.

## Steps:
1. Click Upload .CSV file here
2. Select your CSV file
3. Click Upload
4. Review the contact count and any error messages in the import summary
5. *(Optional)* Turn on Invite to Perchwell to invite every contact in the file
6. Click Submit

Perchwell adds the contacts without errors to the Contacts page and skips any row with an error.

# Fix bulk upload errors in the import summary

Fix bulk upload errors by correcting the rows Perchwell skipped and uploading only those rows again. The import summary shows an error message for each problem it finds, such as:
- Email must be a valid email: An email address in the file is not in a valid format. Correct the address, such as a missing @ or domain.
- Email can't be blank: A contact in the file has no email address. Add one, or remove that row.
- Email already exists: The email address already belongs to one of your contacts. Remove that row from the file.

## Steps:
1. Delete the rows that imported from your CSV file, keeping only the rows with errors
2. Correct each error
3. Save the file in CSV format

Upload the corrected file with the steps in Upload the CSV file and review the import summary.

> **Tip:** If the bulk upload still fails, download the CSV template again and paste your contacts into its columns.

# Invite bulk uploaded contacts to Perchwell

Invite bulk uploaded contacts to Perchwell as you upload them, with Invite to Perchwell on the import summary, or later from each contact's profile or all at once from the Actions menu on the Contacts page. [Invite Clients to Perchwell and Resend Invitations](https://support.perchwell.com/crmls/en/articles/18516368-invite-clients-to-perchwell-and-resend-invitations) explains each way to send an invitation.

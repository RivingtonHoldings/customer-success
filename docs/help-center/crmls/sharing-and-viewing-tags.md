# Generate a Shareable Tag Link

Each tag includes a share option that creates a public link to the listings inside the folder.

## Steps
1. Go to the **Tags** page.
2. Use the search bar to locate the tag you want to share.
3. Click the **Edit (pencil)** icon next to the tag.
4. Click **Share Tag**.
5. Copy the generated link and send it to clients or external recipients.

# Quickly Copy a Tag Link

You can also copy the tag link directly from the Tags list.

## Steps
1. Go to the **Tags** page.
2. Click **Click to view and filter tags**.
3. Locate the tag you want to share.
4. Click the **share link icon** next to the tag name.

The link will copy instantly so you can paste it wherever needed.

# What Clients See

Anyone who opens the tag link will see a client-facing page displaying the listings saved in that tag.

✅ The shared page includes:
- Listing photos
- Key property details
- Links to view individual listing pages

❌ The shared page **does not include**:
- Listing agent contact information
- Internal listing details
- Private documents or notes

# Tips
- All listings saved in the tag folder appear in the shared link.
- The page updates automatically when listings are **added, removed, or updated** in the tag.
- You can use tag links to share **curated property collections** with clients or marketing channels.

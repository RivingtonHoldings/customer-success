# Customize Your Dashboard

Use this article to choose which widgets display on your Dashboard, reorder them into your preferred layout, and sort the list in each widget. A Dashboard widget displays one kind of information.

# Choose which widgets display on the Dashboard

Choose which widgets display on the Dashboard from Manage widgets, in the top right corner of the Dashboard. Contacts, Saved Search, and Tags each have a checkbox. Hot Sheets does not: the panel has an Add hot sheet action instead, and a Dashboard can hold more than one Hot Sheet.

## Steps:
1. Click the Manage widgets button in the top right corner of the Dashboard
2. Check Contacts, Saved Search, or Tags to add that widget, or uncheck it to remove it

The Dashboard updates as soon as you check or uncheck a widget. A green confirmation message appears at the bottom of the screen showing Widget added or Widget removed.

To add a Hot Sheet, click the Add hot sheet button at the top of the Manage widgets panel. The Hot Sheets widget is added to the Dashboard immediately. Unlike the checkboxes, no confirmation message appears.

[Add a Hot Sheet to the Dashboard](https://support.perchwell.com/crmls/en/articles/18232986-add-a-hot-sheet-to-the-dashboard) covers how to set one up.

> **Note:** The Listings widget is not in Manage widgets, because it cannot be added or removed. It is always on the Dashboard.

# Reorder your Dashboard widgets

Reorder your Dashboard widgets by dragging one into the position you want. The drag handle is the six dots to the left of the widget's name.

## Steps:
1. Find the drag handle on the widget you want to move
2. Drag the widget to its new position

The new order is saved automatically, and it is still there the next time you open the Dashboard.

> **Note:** The Listings widget cannot be moved out of its position.

# Sort a Dashboard widget

Sort a Dashboard widget from the icon in its top right corner.

## Steps:
1. Click the icon in the top right corner of the widget
2. Select an option under Sort by

The sort options vary by widget:
- Contacts: Name or Recently Created
- Saved Searches: Name or Recently Updated
- Tags: Name or # of Properties

The Listings widget works differently. [Find Listings in the Listings Widget](https://support.perchwell.com/crmls/en/articles/18233020-find-listings-in-the-listings-widget) covers choosing whose listings you see, using status and activity filters, and finding a listing that is missing.

# Things to Know
- The Dashboard and Hot Sheets are not available in the Perchwell mobile app. Both open on desktop only
- For what each widget shows and the workflows that start from it, see [Dashboard Overview](https://support.perchwell.com/crmls/en/articles/18233009-dashboard-overview)

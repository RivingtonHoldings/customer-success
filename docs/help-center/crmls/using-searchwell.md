# Using Searchwell

# In this article:

You will learn how to run a Searchwell search from the **Search** page, understand what happens to existing filters, refine results, and save your search.

# Run a Searchwell search (use **AI Search**)

Use Searchwell to turn a natural-language request into filters on the **Search** page.

### To run a search:
1. Navigate to **Search**
2. Click **Filters**
3. Locate **AI Search**
4. Type your criteria in natural language
5. Click **Search**

###
Try these example queries:
- **Waterfront condos in Gulf Shores under $800,000**
- **Active listings in Foley with a pool**

> 💡 Put the details you care about in one sentence. Searchwell converts your text into the closest matching filters.

# Understand how Searchwell applies filters

When you run Searchwell, it replaces your current filter set.
​

### Here is what happens:
- Searchwell clears existing filters.
- Searchwell applies new filters based on your **AI Search** text.
- Results update based on the new filters.

> 💡 If you already set filters manually, run Searchwell only when you want to start over with a new filter set.

# Refine results after Searchwell runs

After you see results, narrow them further with standard filters and tools.

Common next steps:
- Add or adjust filters (price, status, bedrooms, bathrooms, location).
- Update **Property Type**.
- Use map tools to refine geography.
- Change columns and sorting.

To replace the search, type a new query in **AI Search** and click **Search** again.

# Save a search created with Searchwell

Save your Searchwell results the same way you save any search.
1. Run your Searchwell query.
2. Refine your results.
3. Click **Save Search**.
4. Enter a name.

Saved searches appear in your saved searches list.

# When to use Searchwell

Use Searchwell when you want to start quickly from a sentence instead of building filters one by one.
​

### Searchwell works well for:
- Translating client criteria into filters.
- Starting a new search from scratch.
- Testing new criteria quickly.

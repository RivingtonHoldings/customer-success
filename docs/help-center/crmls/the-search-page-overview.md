Search is built to streamline your daily workflow and keep everything moving. From this page, you can:

# Create and Save a Search

Create a new search to begin applying filters and organizing results.

### Steps
1. Click **Create New Search**.
2. Enter a name for the search.
3. Click **Save**.

To confirm you are in the correct search:
- Open the **Saved Search** dropdown.
- Verify the active search name.

## Use the Saved Search Dropdown

The Saved Search dropdown allows you to manage and access saved searches.

From this menu, you can:
- View previously saved searches
- Switch between searches
- Set alerts
- Apply templates

## Save Changes to an Existing Search

Use **Save Changes** to update a search after modifying filters or layout.

[![image](https://downloads.intercomcdn.com/i/o/trq7czv5/2127398841/520b5870b62e8103f366f34481be/Group-2B412.png)](https://downloads.intercomcdn.com/i/o/trq7czv5/2127398841/520b5870b62e8103f366f34481be/Group-2B412.png?expires=1788542100&signature=62fc5987124160350b839143016e0dfaf48501edd7098c3f737eed960b88464e&req=diElEcp3lYlbWPMW1HO4zTnL8wYanT6JAhRA%2BffiWk4XAo5ptlPp8S3oAeKx%0At89Ssb%2FFw5Vame%2BC6E4%3D%0A)

### Steps
1. Apply new filters or adjust your layout.
2. Click **Save Changes**.

> 💡 If you applied filters before clicking **Create New Search**, clicking **Save Changes** allows you to name and save the search.

Once saved, the button will display **Saved**.

## Use Universal Search

Use Universal Search to quickly locate a specific listing, agent, or contact.

The Universal Search bar is located in the top right corner of every page.

Enter:
- An address
- An MLS number
- An agent name
- A contact name or email

Selecting a result opens the corresponding page.

# Filter Listings

Use filters to narrow results based on property details, status, and location.

## Use the Filters Button

The Filters button provides access to commonly used and advanced filters.

### Steps
1. Click **Filters**.
2. Select the filters you want to apply.

To access the full list of available filters:
- Click the **+** icon.
- Select additional filter options.

Selected filters appear as filter columns on the Search page.

## Use Filter Columns

Filter columns allow you to adjust criteria directly from the Search page.

You can:
- Click the dropdown arrow in a column to modify parameters.
- Drag and drop columns to reorder them.
- Click the **X** to remove a filter column.

## Use Active Filter Bubbles

Active filters appear as bubble tiles at the top of the Search page.
- Active filters are highlighted in the filter row and Filters panel.
- Removing a bubble removes the corresponding filter.

# Customize Map and Listing Views

Adjust the layout to control how listings and map data are displayed.

## Adjust Listing View

Choose from:
- Grid view
- Compact List view
- Expanded List view

Switch views using the layout controls above the results.

## Adjust Map View

Resize or hide the map to change the screen layout.

You can:
- Select ¾, ½, or ¼ view.
- Click the hide icon to collapse the map.

# Export Listings

Export listing data for external use.

## Steps
1. Click **Export**.
2. Select a template or create one.
3. Download the file as a CSV.

Templates may include predefined formats provided by your MLS.

> 📖 Dive into this article to learn more about **[exporting listings](https://intercom.help/perchwell-help-center-crmls/en/articles/11776740-exporting-listings-in-perchwell)** in Perchwell.

# Use Analytics

[![image](https://downloads.intercomcdn.com/i/o/trq7czv5/2127819496/2c643d6e759993beebba02f0550b/image-2B-2812-29.png)](https://downloads.intercomcdn.com/i/o/trq7czv5/2127819496/2c643d6e759993beebba02f0550b/image-2B-2812-29.png?expires=1788542100&signature=507adcd626f9045e4a52dbcd2873ba96dee5a04ff3e059cad9df4f14ef53332e&req=diElEcF%2FlIVWX%2FMW1HO4zakCYpM1sVCmPyqdzafwZFkgvKFpWfMaf0xv5j9v%0AQeNjieXB4JxC%2FRunD%2F0%3D%0A)

Access Analytics for chart-based data tied to your current search.

## Steps
1. Click the **Analytics** tab.
2. Select or create charts.
3. Export charts as PDF or email them.

Analytics reflects the filters currently applied to your search.

> 📖 Check out this article to explore **[analytics](https://intercom.help/perchwell-help-center-crmls/en/articles/8955860-analytics-overview)** in more detail.

# Tip
- Searches must be saved before alerts can be set.
- Active filters update results automatically.
- Layout adjustments do not change filter criteria.
- Analytics and exports reflect your current search filters.

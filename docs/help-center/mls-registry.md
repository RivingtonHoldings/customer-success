## Readiness

Read fresh on every run from the table headed "MLS publishing readiness" on the Help Center Production Tracker page (ID 3dd8b9e0143881bbbaf4ea0964bd34f9). Columns: MLS, Ready to publish, Owner, Notes. Rows are matched to the display name above, ignoring case.

- Yes: ready for new articles, `all`, and updates.
- No: no new records for that MLS and excluded from `all`; updates to existing records still work.
- Paused: blocks everything for that MLS, updates included.
- A missing row, a blank, or an unreadable table counts as No for new records and `all`, and never blocks an update.

## Collections

Which help center owns each collection is in `docs/help-center/collections.md`. It is regenerated by `/sync-help-center`; do not edit it here.

## Adding an MLS

1. Add a column above.
2. In the Notion database, add the `MLS` option and the three fields named in the column.
3. Add a row to the readiness table on the Production Tracker.
4. Run `/sync-help-center` so the collection map and mirror folder exist.
5. Leave Ready to publish at No until its help center articles are ready.

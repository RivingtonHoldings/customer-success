# Link exceptions

A link in an article must go to that MLS's own article. When a linked article has no published version for the target MLS, `/port-to-intercom` flags the link and Tara chooses: stop, publish without the link, or approve a named exception. This file records only the approved exceptions. A link that was stopped on or published without its link needs no entry.

Written by `/port-to-intercom` after a confirmed push, never by hand. Read on every later publish of the same article, so each exception is listed again as a reminder.

## How an exception works

- It covers one link in one article for one MLS, pointing at one named destination. It never covers another link, another article, or another MLS.
- Tara names the exact destination (title, MLS, URL). The confirmation repeats it with a warning that readers of the target MLS would leave their own help center.
- If the destination changes, Tara is asked again.
- When the missing article is created for the target MLS, the next publish of the linking article offers to replace the exception with the correct link. After a yes, the status becomes Replaced.
- "Approve all" is not accepted. Each exception is approved on its own.
- Statuses: Active (in the published article), Replaced (the correct link now exists), Removed (the link was later taken out of the article).

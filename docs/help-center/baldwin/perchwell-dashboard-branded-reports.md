# Perchwell Dashboard & Branded Reports

This session covers how to use the Perchwell dashboard and create branded reports. You’ll learn how to customize widgets and layouts, set up Hot Sheets, manage saved searches, and use integrations. We’ll also cover creating reports and building CMAs from your search data. Ends with live Q&A.

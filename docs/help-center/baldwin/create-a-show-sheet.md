# Create a Show Sheet

# When to use a Show Sheet

Use a Show Sheet when you need a presentation-ready summary of a property.
- Prep materials for a buyer showing
- Share property details during a client consultation
- Print a property summary for an in-person meeting

# Show Sheet creation

Choose the starting point that matches how you selected your listings.

## Start from Search

Use this option when you want to include one or more listings from your search results.

### Steps:
1. Open **Search page**
2. View listing results by clicking **Search**
3. Select the checkboxes next to the listings you want to include
4. Click **Actions**
5. In the drop down, click **Create a Report**
6. Select **Show Sheet**

## Start from the Listing Detail Page

Use this option when you are creating a Show Sheet for one listing.

### Steps:
1. Open a listing from **Search** or **Universal Search**
2. Open the actions panel on the right
  - Hover near the right edge of the page, or
  - Click the **actions button** in the top right
3. Click **Add to Report**
4. Select **Show Sheet**

# Show Sheet customization

After you select **Show Sheet**, review the report settings and choose what recipients will see.

[![image](https://downloads.intercomcdn.com/i/o/trq7czv5/2158682869/0f4cb8dc20d1488164a635582982/image.png)](https://downloads.intercomcdn.com/i/o/trq7czv5/2158682869/0f4cb8dc20d1488164a635582982/image.png?expires=1788542100&signature=de1401a919bf451ee25a44911c7f329615e6d9195129d4d717af70e668dce69c&req=diEiHs92n4lZUPMW1HO4zYfEAFewwD%2FwMQZA417Pe9uIaIc1hzE9oyhxKJF5%0AcXjwnLSjVS5DeZf9TEw%3D%0A)

## Choose how listing links open

Set what happens when someone clicks a listing link in the report.
- Select **Open in Perchwell**
- Select **Open externally with your branding**

## Select the fields to display

Choose which listing details appear on the Show Sheet.
- Include exact address
- Include Days on Market (DOM)
- Include open house information
- Include list date
- Include transit information
- Include map
- Include floor plan
- Include status
- Include neighborhood
- Include cross streets

## Select which contact information appears

Choose the contact details that show on the report.
- Select **Listing agent information**
- Select **Your contact information**
- Select **None**

## Choose the page orientation

Select how the report is formatted.
- Select **Portrait**
- Select **Landscape**

## Reorder or remove listings

Adjust the listings included in the report before you share it.
- Drag and drop listings to reorder them
- Click the **X** to remove a listing

When finished, click **Next**.

# Show Sheet sharing

After you review your Show Sheet, choose how you want to distribute it.

## Email the Report

### Steps:
1. Select **Email**
2. Enter the recipient’s email address
3. Update the subject line
4. Review the message body and make edits as needed
5. Click **Email Report**

You and the recipient both receive a copy.

## Download the Report

### Steps:
1. Select **Download**
2. Wait for the PDF to generate
3. Save the file to your device

## Print the Report

### Steps:
1. Select **Print**
2. In your browser’s print dialog, choose your printer and settings
3. Click **Print**

## Tips
- Show Sheets work well for single-property presentations and detailed property reviews.
- Include multiple listings when you start from **Search** or **Tags**.
- Find saved reports in your **Report Library**.
- Search for a report using the recipient’s email address.

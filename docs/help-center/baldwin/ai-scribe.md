# AI Scribe

# AI Scribe overview

Use **AI Scribe** to create a first draft of your listing’s **Listing Description** using the details you entered in the listing form.
- Generate a description from your listing inputs
- Pick a writing style that matches your audience
- Edit the generated text before you submit the listing

[Embedded video](https://www.loom.com/embed/df6bb7afd8fe4112a62fdc705eac070a)

# Locating the AI Scribe in the Add/Edit form

**AI Scribe** lives in the **Add/Edit Form**.

### Steps:
1. Open **Manage Listings** from your dashboard
2. Click **Create New Listing** or open an existing listing to edit
3. Complete the required property details
4. In the **Listing Description** section, turn on **AI Scribe**

# Listing description generation and refinement

Set your preferences, generate a draft, then review and edit it.

## Choose how you want the description to sound
- Select a tone, such as ***Professional***, ***Energetic***, or ***Neutral***.
- Select a length, such as ***Short***, ***Medium***, or ***Long***.

## Highlight what you want to feature

Use the emphasis options to focus the description on details like:
- Building amenities
- Location highlights
- Room types and layouts
- Other key features you want to call out

### Steps:
1. Click **Generate**
2. Review the draft in **Listing Description**
3. Edit the text to match your listing, brand, and audience before you submit

# Fair housing and accuracy

Review every AI-generated description before you publish it.
- Confirm the description is accurate and reflects the listing details you entered.
- Check the language for fair housing compliance.

# Search for a Condo

# Search for Condos in a City

## Use Property Type and Property Sub-Type Filters (Recommended)

[![image](https://downloads.intercomcdn.com/i/o/trq7czv5/2453634741/f4bf72afd287563abb2fd6fc4b25/Group+111.png)](https://downloads.intercomcdn.com/i/o/trq7czv5/2453634741/f4bf72afd287563abb2fd6fc4b25/Group+111.png?expires=1788542100&signature=a5ab67f20c3ca169f011fd9f4623825b5750835b0eed05cf93a8ce91a85eb644&req=diQiFc99mYZbWPMW1HO4zXFM8K6T9hLOwaH35Y9BMhMdwpNjmZ4Pp61cNTWC%0A2rOzmZirgAeUmUluT%2FU%3D%0A)

This is the most common way to search for condos.
1. Set **Property Type** to **Residential – Single Family**
2. Set **Property Sub-Type** to **Residential Attached**

This search will return condominium listings that are classified as attached residential properties.

## Use Structure Style Filter

[![image](https://downloads.intercomcdn.com/i/o/trq7czv5/2453635818/6b607a1ffe87b209647ca22e9e1f/Group+109.png)](https://downloads.intercomcdn.com/i/o/trq7czv5/2453635818/6b607a1ffe87b209647ca22e9e1f/Group+109.png?expires=1788542100&signature=8029ea7ffa7ac2e21c59cb288f7c65babbd5cc38214cefa2288323c2e3e278cd&req=diQiFc99mIleUfMW1HO4zUJvxcXVim1D8nL7NQxc7DseHooWyD60uMt4VAlN%0A26Q0cr5MDBEtaSZkBoo%3D%0A)

You can also search for condos by filtering on the property's structural style.
1. Open your search filters
2. Set **Structure Style** to **Condo**

This method is useful when you specifically want properties identified as condominiums.

# Search for a Specific Condo Complex

## Search by Subdivision Filter or Condo Name

[![image](https://downloads.intercomcdn.com/i/o/trq7czv5/2453638069/9e428abecd50109e29de1d697649/Group+112.png)](https://downloads.intercomcdn.com/i/o/trq7czv5/2453638069/9e428abecd50109e29de1d697649/Group+112.png?expires=1788542100&signature=b75bd072259e86a898d0af39e288ce490cbf22b754a5d688cabe765c35e7fadb&req=diQiFc99lYFZUPMW1HO4zbU7CUEqB02xY6SebtDaUKoZkkjoLFe44D%2Fr2cGE%0AwDm2hTA5Io74BRtLcDs%3D%0A)

If you're looking for listings within a specific condo community or complex:
1. Use the **Subdivision/Condo** search field
2. Enter the name of the condo complex (for example, **Jubilee Farms**)
3. Run your search

This will return listings associated with that specific condo development or community.

# Appraiser Capabilities in Perchwell

## In this article

You’ll learn how to:
- Search for active and closed listings within a specific date range.
- Apply filters to identify relevant comparable properties.
- Customize your results columns for appraisal research.
- Tag comparable listings and reviewed listings.
- Save Full Reports for your records.
- Use analytics to support appraisal adjustments.
- Export comparable listing data to CSV.

## Apply filters to segment the market for a comp search

Start with a closed listing search that reflects the subject property you are appraising.

**Steps:**
1. Open **Search.**
2. Click **Filters.**
3. Set **Property Type** and **Property sub-type.**
4. Set **Status** to **Closed.**
5. Set a date range. A common starting point is one to one and a half years back.
6. Add filters for Bedrooms, Bathrooms, SQFT range, and any additional differentiating attributes.

## Set up your columns for appraisal fields

Customize your column view to surface the data points most relevant to your appraisal report.

**Steps:**
1. From the **Search** page, go to the **Results** view.
2. Click the **Columns** drop-down.
3. Select the fields you want to display, such as:
  1. Square footage
  2. Lot size
  3. Year built
  4. Beds
  5. Baths
  6. Sale price
4. Drag and drop columns to reorder your view.
5. Deselect any columns you do not need.
6. Save the template with a name you’ll recognize later.

> **💡 You can save this layout and additional ones as a template so you can return to the same column setup for future reports based on property type, amenities, or any other key criteria. Learn how to save a column template in this article.**

## Review and tag your comparable listings

Review each listing to determine whether it is a suitable comparable. Tag the listings you plan to use, and keep a separate tag for listings you reviewed but did not use.

**Tag listings you are using:**
1. From the listing detail page, open the **Action** panel.
2. Click **Tags.**
3. Select an existing tag or create a new one (example: 123 Main St - DATE - Comp).
4. Repeat for each comparable you plan to include in the report.

**Tag listings you reviewed but did not use:**
1. Follow the same steps above.
2. Apply a separate tag (example: 123 Main St - DATE - Comps Reviewed).

> **💡 Keeping both sets of tagged listings helps you stay organized across multiple reports and supports documentation requirements.**

## Save a Full Report for your records

Use the Full Report to review listing details and support data entry into your appraisal software.

**Steps:**
1. Open a tagged comparable listing.
2. Hover over the actions panel.
3. Select **Full Report.**
4. Print or save the report to your computer.

> **💡 Print a Full Report for each comparable you plan to use. Some states require documentation of every listing you considered, not just the ones you included in the final report.**

## Run analytics to support your adjustments

Use Analytics to identify trends and calculate market adjustments, such as price per square foot or value differences between bedroom counts.

## Use Search Analytics View

To analyze selected listings from a filtered search, use the **Search Analytics View**.

## **Steps:**
1. From your search results, switch to the **Analytics** view.
2. Review median price and price per square foot to spot trends between comparables.
3. Narrow your filters further to isolate specific variables.
For example, use exact bedroom count or a tighter square footage range.

> **💡 Use this method to determine adjustments by comparing two listings that are identical except for one variable, such as one extra bedroom or a pool.**

## Use Market Analytics

To analyze listing data across the entire market or a market segment, use **Market Analytics** on the Analytics page.

## **Steps:**
1. Select **Analytics** in the top navigation bar.
2. Choose the **Market Analytics** report.
3. Adjust criteria based on property type, county, date range, and other available filters.
4. View the results and AI Summary.

## Download your comparable listings as a CSV

Export comparable listing data to CSV for use in data entry or appraisal reporting.

**Steps:**
1. From the **Results** view, select the checkboxes next to the listings you want to export.
2. Click **Actions.**
3. Select **Export to CSV.**
4. Select the desired template, or choose a custom appraiser template created by you or provided by your brokerage.

## Tips
- If the subject property has an existing listing in the MLS, you can open it directly from Universal Search. Keep in mind that listing data may be outdated if significant time has passed or improvements have been made.
- The Full Report is the best format for transferring comparable data into appraisal software. It contains the listing details needed to complete comp entries accurately.

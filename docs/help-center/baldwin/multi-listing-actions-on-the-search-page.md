# Multi-Listing Actions on the Search Page

# Select multiple listings

Select listings first. The **Action drop down will appear in the display.**
1. Go to the **Search** page
2. View search results by clicking **Search**
3. Select the checkbox next to a listing
4. Click the **Actions** drop down

[Embedded video](https://demo.arcade.software/tSIDOux6w4kRnQ7tQPsR?embed)

💡 **Select everything in view by clicking *Select All* in the Action Panel.**

# Use the **Action Panel** to take bulk actions

The **Action Panel** gives you quick actions for the listings you selected.

## Create, share, and organize listings

Use these actions to package listings for clients or keep your work organized.

| **Create a Report** | Add the selected listings to a CMA, Listing Report, or other available report |
|---|---|
| **Share via Messages** | Send the selected listings to invited clients using **Messages** |
| **Share** | Send listings by **Email** or generate a **Public Link** |
| **Tag** | Add the selected listings to one or more tags |
| **Open in New Tab** | Open the selected listings in a carousel so you can compare them quickly |

## Contact people and schedule next steps

Use these actions when you need to communicate or set up appointments

| **Contact Agent** | Email the listing agent for each selected listing |
|---|---|
| **Schedule a Showing** | Schedule showings using **ShowingTime** (availability varies by MLS) |

## Tips
- Use **Open in New Tab** to full listing detail pages in a different tab.
- Some actions depend on your permissions and connected services
- If you hide a listing, it no longer appears in your current search results

# Understand Status and Activity Filter

# Understand** Status** vs. **Activity**

Use these filters together to narrow results by the listing’s current MLS status and recent changes.

## **Status** shows what the listing is right now
- Filter by the listing’s current MLS status (example: **Active**, **Pending**, **Closed**).
- Combine with other filters to narrow results (price, location, beds, baths).

## **Activity** shows what changed during a timeframe

Track changes that happened within a window you set.
- Filter by a change type (example: **Price Drop**).
- Set the timeframe using **Date Range** or a trailing window.

**Example:** Find listings that are currently **Active** and have had a **Price Drop** in the last 30 days.

# Open **Property Status** in **Filters**

### Steps:
1. Click **Search** to get to the Search page
2. Click **Filters**
3. Scroll to **Property Status**

# Set **Current Status**

Choose the current statuses you want included.
1. Select one or more Statuses (example: **Active or Pending**).

# Set an **Activity** filter and timeframe

[Embedded video](https://demo.arcade.software/0yyPSAepaeTxyH9XBgxH?embed)

Use **Activity** when you need listings that changed recently.
1. Select an activity type (example: **Price Drop**).
2. Set your timeframe by clicking **Any Date**:
  - Choose **Date Range** to pick start and end dates.
  - Use the **Rolling window** fields to look back a set number of days.
  - Select **Reporting period** to select a fixed date for reporting periods like month-to-date or year-to-date.
3. Click **Submit**.

Results update automatically after you confirm.

## Example: Find **Active** listings with a recent **Price Drop**

### Steps:
1. Set **Status** to **Active**.
2. Set **Activity** to **Price Drop**.
3. Choose **Date Range**, then click 30 days.
4. Click **Confirm**.

## Tips
- Start with **Status**, then add **Activity** to find recent changes.
- Narrow results further with filters like **Location**, **Price**, **Bedrooms**, and **Bathrooms**.
- Save the search so you can revisit it without rebuilding filters.

# How To Run a Map Search

## **Run a map search, part 1: the radius tool**

When a client cares about a specific spot rather than a whole city, start on the map. This covers drawing a radius and adding commute distances so results line up with where they actually need to be.
​
​

[Embedded video](https://www.loom.com/embed/2d0310b38f004531a83e4cfa7087aa2d)

## **Run a map search, part 2: polygons, freehand, overlaps, and exclusions**

The rest of the map toolkit. Draw a polygon or a freehand shape, stack several shapes together, choose whether you want everything inside all of them or only the overlap, and carve out an area you want excluded.

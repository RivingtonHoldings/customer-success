# Tags FAQ

## Do the links for tags or public links expire?

Tags and public links do not expire. The listing details page will automatically update if any changes are made to the listing. If you add or remove listings from a tag, the page will update automatically to reflect your changes.

## Can clients add or remove listings in a tag?

Clients can not add or remove listings in a tag that you’ve shared. When you share a tag, clients can only view the listings. For a more collaborative back-and-forth with your client, we recommend using the Messages feature, where they can react to listings by liking, disliking, or marking them as a maybe.

## What is the difference between sharing a Tag and sharing a public link?

Both options allow clients to view listings without logging in to Perchwell, but they serve different purposes:
- **Tags** are custom folders that can be shared directly with a client. They include a dashboard that automatically updates whenever listings are added or removed. This is ideal for ongoing searches where the collection of listings will change over time.
- **Public links** are a quick, one-time share. The link captures a set of listings at a specific moment and does not update automatically. This option is best for sharing listings quickly outside of Perchwell via text or email when you don't need the list to stay current.

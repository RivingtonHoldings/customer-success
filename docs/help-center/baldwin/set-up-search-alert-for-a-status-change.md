# Set up Search Alert for a Status Change

## **Set up Search Alert for a Status Change**

Save a separate search and set alerts for each status you want to monitor. Your client will automatically receive updates when a matching listing changes to that status, keeping them informed while you stay in the loop. **A more streamlined approach is coming soon!**

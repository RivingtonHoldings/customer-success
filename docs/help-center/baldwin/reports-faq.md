# Reports FAQ

Use this article to answer common questions about Perchwell reports: changing a report's layout, choosing Quick CMA (Comparative Market Analysis) fields, turning on Include exact address, creating a Quick CMA for lease listings, hiding Full Report sections, sharing a report, and finding past reports in your Report library.

# Can I customize the layout of my reports?

Perchwell reports follow set layouts designed by your MLS staff and Perchwell, so not every field position can be changed. Choose what goes in each report on the Customize Report step of the report window:
- Quick CMA: Select Landscape or Portrait, then select the fields each listing shows. Add a subject property, listings from a Tag, your contact information, or a summary section.
- Listing Report: Enter a Report Label and Report Subtitle, and select Landscape or Portrait. Select details such as DOM, Open house, and Large map.
- Show Sheet: Select Landscape or Portrait, select details such as Map and Floorplan, and choose whose contact information shows. Arrange up to 13 photos.
- Itinerary: Set the tour date and times, and add an appointment time and notes to each stop. Add your client's name, and select details such as Agent name and Exact address.
- Full Report: Select For agent, For client, or Both, and choose whether to include listing history.
- One Pager: Select For agent, For client, or For both.
- Media Report: Drag the listings into the order you want. The report includes the first 15 images from each listing.
- 1004MC Market Conditions Addendum: Select Landscape or Portrait, set the Max List Date, and set the stable range.

Reorder or remove listings in a Quick CMA, Listing Report, Show Sheet, Itinerary, or Full Report on the same step. Drag a listing to move it, or click the X to the right of a listing to remove it.

Members who came from a legacy platform may know customizable reports, such as Agent All Fields Customizable and CMA Summary.

# What fields can I include in a Quick CMA or a CMA with a subject property?

A Quick CMA shows up to 12 fields per listing with the Landscape layout, and up to 9 with Portrait. Fields include Beds, Baths, SQ FT, $/SQ FT, DOM/DAM (Days on Market or Days Active in MLS), Year Built, and MLS ID.

Select the fields under Select fields to show on the Customize Report step of the report window. A CMA with a subject property opens the same Customize Report step, which means the same fields and limits apply.

[Create a Quick CMA Report](https://support.perchwell.com/baldwin/en/articles/13959293-create-a-quick-cma-report) lists every field available in a Quick CMA.

# What does Include exact address do in a Quick CMA?

Include exact address shows each listing's full street address in the Quick CMA, with the unit number where one applies. Select it under Additional Options on the Customize Report step.

With Include exact address selected, each address in the PDF (Portable Document Format) file is a link. Your choice under Select where links should open decides where it goes:
- Open links externally with your branding: Opens the listing on a page with your branding.
- Open links in Perchwell (clients must log in): Opens the listing in Perchwell after the client logs in.

# Can I create a Quick CMA for lease listings?

Yes. Create a Quick CMA for lease listings the same way as for homes for sale. Select a lease property type, such as Lease or Residential Lease, under Property Type on the Search page, then select the listings you want for the Quick CMA.

[Create a Quick CMA Report](https://support.perchwell.com/baldwin/en/articles/13959293-create-a-quick-cma-report) covers each step from your search results.

# How do I hide sections of a Full Report from clients?

Hide sections of a Full Report by collapsing them on the Listing Detail Page before you print.

## Steps:
1. Click the arrow next to each section you want to hide
2. Click Actions in the upper right
3. Select Print full report
4. Select For agent or For client in the Print report window
5. Click Print

The Full Report opens in a print preview window, and the sections you collapsed are left out completely. This applies to both the For agent and For client versions.

Collapsed sections carry over only to a Full Report printed from the Listing Detail Page. To hide sections, print the Full Report from the listing rather than creating it from your search results.

# How do I share a report with a client?

Share a report with a client from the Generate Report step of the report window. Click Next on the Customize Report step to open it, then choose how to share:
- Email Report: Sends the report to the email addresses you enter.
- Print: Opens your browser's print dialog.
- Download: Saves the report to your computer as a PDF file.

[Create a Quick CMA Report](https://support.perchwell.com/baldwin/en/articles/13959293-create-a-quick-cma-report) and [Create a Full Report](http://support.perchwell.com/baldwin/en/articles/12816757-create-and-share-full-reports) explain the email fields for each report.

# Where do I find a report I already created?

Find a report you already created in your Report library, which opens from the profile menu.

## Steps:
1. Hover over your profile icon in the upper right corner
2. Click Report library

Your Report library opens with your saved reports. Search for a report by the recipient's email address.

# Do I need a listing to use as the subject property in a CMA?

No, you do not. Click Add Subject Property in a Quick CMA and enter the details by hand

# Can I print all of a listing’s photos?

No single report has listing details plus every photo. A Media Report has the first 15 images from each listing. A Show Sheet adds up to 13 photos with the listing details. Sharing the listing via a public link or email will show every photo.

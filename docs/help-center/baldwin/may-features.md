# May Features

**Subject Property CMA:** We’ve simplified and improved the process of creating a CMA with a subject property. Now simply launch the CMA Subject Property from the Listing Detail page, where you can modify the criteria and run a search based on the details of the subject property.

➡️ **[Learn More](https://intercom.help/perchwell-help-center-baldwin/en/articles/15216797-create-a-cma-with-a-subject-property)**

**Status & Activity** Filter: We’ve combined this tool into one, making it easier to adjust the date range on any status filter with a few clicks.

➡️ **[Try it out](https://www.perchwell.com/results)**

**Firm Ranking Report**: The Firm Ranking report has been added to the Analytics Tab to view Firm data. See the highest performing Firms, Sold Volume, and more. Including the already loved AI Summary to easily get an idea of what’s happening across Firms.

 ➡️ **[Check it out now](https://www.perchwell.com/analytics)**

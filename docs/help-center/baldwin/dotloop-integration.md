# Dotloop Integration

## In this article:

You will learn what the Dotloop integration does, how to open dotloop from a listing's **Listing Detail** **Page**, and what to expect after the handoff.

# What the Dotloop integration does

Dotloop is a transaction management tool. The Perchwell integration adds a **Dotloop** option to every listing's **Listing Detail** page. Click it, and dotloop opens in a new tab with a new loop pre-filled from the listing's address and MLS identifiers, which means you start the transaction without retyping property details or introducing typos between the two systems.

The integration is a handoff, not a two-way sync:
- Perchwell sends the listing's address and MLS identifiers to dotloop once, when you click **Dotloop**
- Dotloop creates the new loop on its side. Nothing changes inside Perchwell
- Documents, people, and updates you add to the loop stay in dotloop

# Requirements
- A dotloop account. The integration opens dotloop; it does not create an account.
- Your dotloop credentials. Perchwell does not sign you in automatically, which means dotloop asks you to sign in when it opens.

# Open dotloop from a listing

The integration lives on the **Listing Detail** page, so open the listing first.

### Steps:
1. Go to **Search**
2. Open the listing
3. Hover over the **Action Panel** on the right side of the page
4. Under **Integrations**, click **Dotloop**
5. Sign in with your dotloop credentials

Dotloop opens in a new tab with a new loop pre-filled from the listing. Finish setting up the loop in dotloop.

> **Tip**: Review the pre-filled address and MLS number before adding people or documents to the loop.

# Things to Know
- Each click starts a new loop. The integration does not look up an existing loop for the same property.
- Later edits to the listing in Perchwell do not update the loop, and changes in the loop do not appear in Perchwell.
- The **Dotloop** option appears only on the **Listing Detail** page. There is no dotloop option on Search results or the Dashboard.

> 📖 Learn about the other tools in the **Action Panel** in [Listing Detail Page Overview](https://intercom.help/perchwell-help-center-baldwin/en/articles/14074994-listing-detail-page-overview).

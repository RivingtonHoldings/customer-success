# Add a Hot Sheet to the Dashboard

# When to use Hot Sheets

Hot Sheets are useful any time you need a quick view of listing activity without running a manual search.
- Monitor when a listing similar to one in your office comes on the market to understand the impact on pricing.
- Get a fast view of recent activity on saved searches for each of your active clients who are searching for listings.
- Set up a dashboard for a broker to track activity across multiple offices at once.

# Hot Sheet types

Hot Sheets let you monitor listing changes over a set time frame. There are two types:
- **New Hot Sheets**: Track activity across your MLS by property type, timeframe, and status.
- **Saved Search Hot Sheets**: Track new listings, price changes, and status updates within a specific Saved Search.

# Hot Sheet widget setup

### Steps:
1. Click **Dashboard** in the top navigation
2. Select **Manage Widgets**
3. Click **Add Hot Sheet**
4. The new Hot Sheet widget appears on your Dashboard

# New Hot Sheet setup

Track activity by property type.

### Steps:
1. Click into the **Hot Sheet Widget** and select **New Hot Sheet**
2. Enter a name for your Hot Sheet
3. Choose the property types to monitor
4. Set the time frame
5. Select the statuses to track
6. Save your Hot Sheet

# Saved Search Hot Sheet setup

Stay on top of new listings, price changes, and status updates within a specific search.

### Steps:
1. Click into the **Hot Sheet Widget** and select **From Saved Search**
2. Choose the Saved Search to monitor
3. Set the time frame
4. Select the statuses to track
5. Click **Confirm** to save your Hot Sheet

## Tips
- Monitor activity for up to **2+ years**
- For more precise tracking, create detailed Saved Searches before building a Hot Sheet

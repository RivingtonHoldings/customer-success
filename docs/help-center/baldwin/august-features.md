# August Features

**Reverse Prospecting:** See every active saved search that matches one of your listings, along with the buyer's agent behind it, and reach out directly from Perchwell.

➡️ **[Learn More](https://support.perchwell.com/baldwin/en/articles/16201667-reverse-prospecting)**

**Share via Text:** Text a listing to a contact straight from the Share menu, with delivery status shown in Perchwell.

➡️ **[Learn More](https://support.perchwell.com/baldwin/en/articles/13903326-share-multiple-listings-in-perchwell)**

**Print Search Results:** Print your search results, or save them as a PDF, using the columns you have on screen in the order you arranged them.

➡️ **[Learn More](https://support.perchwell.com/baldwin/en/articles/16302253-print-search-results)**

**Custom Email Signatures:** Personalize the emails you send from Perchwell with a signature that carries your photo, colors, and links. Find it under User Settings, then Signature.

➡️ **[Try it out](https://www.perchwell.com)**

**Enhanced Saved Search Alerts:** Choose how often each saved search sends alerts (immediately, daily, weekly, or monthly) and which changes trigger them: new listings, status changes, price drops, and new open houses.

➡️ **[Learn More](https://support.perchwell.com/en/articles/11112420-set-up-email-alerts-for-saved-searches)**

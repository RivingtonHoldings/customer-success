# Reverse Prospecting

Use **Reverse Prospecting** to see which buyer's agents have active saved searches matching your listings, and reach out to them directly.
- See every active saved search across the platform that matches one of your listings
- View the buyer's agent behind each matched search
- Track shares, views, and tag adds for your listing
- Contact matched buyer's agents directly, without leaving Perchwell

## Review your listing's matches

The listing detail page shows a metrics panel and a matched-searches table so you can see buyer-side interest in your listing at a glance.

## Metrics panel

The metrics panel shows:
- **Matched Searches**: The number of active saved searches that match your listing
- **Contact Views**: How many times your listing's contact information has been viewed
- **Agent Views**: How many buyer's agents have viewed your listing
- **Shares**: How many times your listing has been shared
- **Tag Adds**: How many times your listing has been added to a tag

## Matched-searches table

The matched-searches table lists every saved search that matches your listing, along with:
- **Buyer's Agent**: The agent behind the saved search
- **Brokerage**: The buyer's agent's brokerage
- **Price Range**: The price range set in the saved search
- **Property Type**: The property types included in the saved search
- **Location**: The location criteria set in the saved search

## Contact matched buyer's agents

Reach out to one or more matched buyer's agents directly from the matched-searches table.

**Steps:**
1. In the matched-searches table, select one or more buyer's agents
2. Click **Email**
​[![image](https://downloads.intercomcdn.com/i/o/trq7czv5/2587297067/9bfa11b280bbf490e5167b86e376/redacted_screenshot.png)](https://downloads.intercomcdn.com/i/o/trq7czv5/2587297067/9bfa11b280bbf490e5167b86e376/redacted_screenshot.png?expires=1788542100&signature=74ae3def6cbca8eb7c645201dc48a6cf87126d37eb11afaae586f33194d39328&req=diUvEct3moFZXvMW1HO4za4x7e4Fg0TknRY2ljBzcNCThs8IRnCGgkGVTNhU%0Aupso%0A)
3. Customize your message
4. Click **Send**

#### Perchwell sends your message using the same contact flow you already use elsewhere in the platform.

Listings in Search Column

The **Listings In Search** column means the exact count of listings matching the search criteria in the search saved by that agent. A lower number of listings in their search means your listing is proportionally more relevant to their client's search criteria.

## Turn off Reverse Prospecting for a saved search

Reverse Prospecting is turned on by default for all clients and unassociated saved searches. As a buyer's agent, you can opt a client or an individual saved search out of Reverse Prospecting at any time.

**Steps:**
1. Open the saved search or client you want to opt out
​[![image](https://downloads.intercomcdn.com/i/o/trq7czv5/2585512450/3613495356167dad3fd3aa741620/Screenshot+2026-08-04+at+11_47_36%E2%80%AFAM.png)](https://downloads.intercomcdn.com/i/o/trq7czv5/2585512450/3613495356167dad3fd3aa741620/Screenshot+2026-08-04+at+11_47_36%E2%80%AFAM.png?expires=1788542100&signature=1248941732bc72bd7a3b36ccc714f211f1a08ee43d672bf530f5345edbed707f&req=diUvE8x%2Fn4VaWfMW1HO4zQSPgp8nzqPDpY2LPcgy5ZZYIEdzQopunUIb77vu%0Add2L%0A)
2. Turn off **Reverse Prospecting**
​[![image](https://downloads.intercomcdn.com/i/o/trq7czv5/2585514130/7e139981c58839ab403b4e8a8746/Screenshot+2026-08-04+at+11_48_26%E2%80%AFAM.png)](https://downloads.intercomcdn.com/i/o/trq7czv5/2585514130/7e139981c58839ab403b4e8a8746/Screenshot+2026-08-04+at+11_48_26%E2%80%AFAM.png?expires=1788542100&signature=2521701b3bbbb1759310e1ce205dededcd03e9a58c84c5d45a1489ca122c1f50&req=diUvE8x%2FmYBcWfMW1HO4zfn67JQWmegDkOLOTk7ErOvjXS9czNRFF7u517%2B5%0AyPaQ%0A)

Once turned off, that saved search will no longer appear in listing agents' matched-searches results.

> 💡 **Note**: Reverse Prospecting only surfaces *active* saved searches — paused or inactive searches will not appear as matches.

> 💡 **Note**: Opting a saved search out of Reverse Prospecting does not change how that search runs for the buyer's agent; it only controls whether listing agents can see it as a match.

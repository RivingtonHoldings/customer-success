# Access Integrations from the Dashboard or a Listing

Use this article to open an integration from the Dashboard, find what each Dashboard integration does, and open integrations for a specific listing from its Actions menu.

# Open an integration from the Integrations panel

Open an integration from the Integrations panel on the right side of the Dashboard. The Integrations panel holds the tools your MLS connects to Perchwell.

## Steps:
1. Click Dashboard in the top navigation bar
2. Hover over the right side of the page to reveal the Integrations panel
3. Click the integration you want to open

The integration opens in a new tab, so the Dashboard stays as you left it. When you move away from the Integrations panel, it collapses to show only the integration icons.

Sign in to an integration with the credentials your MLS provided for that tool.

# What each Dashboard integration does

Each Dashboard integration opens a tool your MLS provides. The Integrations panel shows only the integrations your MLS has enabled for your account, so it reflects the tools available to you.
- ShowingTime: Schedule, edit, and cancel showings, and track showing activity
- CRS Login: Open the Courthouse Retrieval System for tax records, property history, ownership information, parcel data, maps, and comparable properties
- InfoSparks: View listing analytics and compare data across geographic areas
- RPR: Open Realtors Property Resource property reports and market analytics
- BR Announcements: Read Baldwin REALTORS® updates, deadlines, and policy changes
- SentriLock: Manage lockbox access

# Open integrations for a listing from the Actions menu

Open integrations for a listing from the Actions menu on its Listing Detail page. Each integration opens for that specific property.

## Steps:
1. Open the listing's Listing Detail page
2. Click Actions in the upper right
3. Click Integrations
4. Click the integration you want to open

The Integrations submenu includes tools also available from the Dashboard Integrations panel, such as ShowingTime, InfoSparks, and RPR, along with tools that open for the specific listing:
- CRS Property Report: View property details, tax records, ownership information, and other public record data
- CRS Comparables: Find comparable properties and review property data for a comparative analysis
- CRS Demographic: View demographic information for the area surrounding the property
- CRS Parcel Map: View the property boundaries and surrounding parcels on a map
- RPR Market Trends: View housing market trends and statistics for the property's area
- Dotloop: Start a Dotloop transaction for the listing with the property details already filled in
- Offer Manager: Open ShowingTime's Offer Manager to view and manage the listing's offers and offer documents
- Report a Listing: Report incorrect listing information to MLS staff

[Listing Detail Page Overview](http://support.perchwell.com/baldwin/en/articles/14074994-listing-detail-page-overview) covers the rest of the Actions menu. [Dotloop Integration](http://support.perchwell.com/baldwin/en/articles/16776673-dotloop-integration) and [Offer Manager Integration](http://support.perchwell.com/baldwin/en/articles/16777012-offer-manager-integration) explain those two tools in more detail.

# Tags Page Overview

[Embedded video](https://www.loom.com/embed/819fcb287f63406fb49f775ae5f33e19)

## A Tag is a shareable collection of listings

A Tag groups listings and the saved searches that feed them, so you can track a set of properties over time and share them as one unit.
- **What it can hold:**
  - Listings you add directly, which stay in the Tag until you remove them.
  - Listings pulled in automatically from a saved search linked to the Tag, which stay in the Tag only while they still match the search. A listing that no longer meets the criteria drops back out on its own.
  - Listings a client adds by reacting to them on a shared Tag page, which stay in the Tag for as long as that reaction (like or dislike) stays active, even if they'd otherwise have dropped out of a linked search. If the client undoes the reaction, the listing can drop back out unless another source still covers it.
- **Example use cases:**
  - Tracking a client's search for a home from first showing to close.
  - Watching a group of properties for price or status changes.
  - Sharing a curated set of listings with one link, without giving the recipient a Perchwell login.

## My Tags vs. client Tags

There are two kinds of public Tag pages: My Tags and Client Tags
- **My Tags**: Tags with no client attached are a landing page of listings. My Tags are useful for personal shortlists, like "Open Houses This Weekend" that can be shared publicly.
- **Client Tags**: Tags with one or more clients attached are designed for collaboration. Tags that are shared with a client allow clients to react to the listings on the page.

A Tag can move from having no client to having one or more, but once a client is added, they can't be removed from that Tag.

## Where you'll run into Tags
- **Tags** tab in the navigation bar: the full list of your Tags.
- **Search **tab in the navigation bar: select multiple listings and share them via Tags
- The **Contacts** detail page: Tags tied to that contact.
- A listing's **Property Detail** page: add the listing to a Tag directly.
- The **Save Search** dialog: link a saved search to a Tag while saving it.

# Tags Page Overview

Use this article to understand how Tags organize listings, tell My Tags from Client Tags, tag listings, and find Tags across Perchwell. A Tag groups listings in one place and has its own public link. Members who came from a legacy platform may know Tags as Listing Carts.

[Embedded video](https://www.loom.com/embed/b1d66ee4abd64e8da5287f7196faf4f9)

# What a Tag holds and how listings stay in it

A Tag holds listings from two sources, and the source determines how long a listing stays in the Tag:
- Listings you add from the Share window stay in the Tag until you remove them.
- Listings from a linked saved search are added and removed automatically as the search results change.

Contacts cannot add listings to a Tag you share with them. If a contact likes or dislikes a listing from a linked saved search, the listing stays in the Tag even if it no longer matches the search. Once the reaction is removed, the listing automatically leaves the Tag.

[Add Listings to a Tag](http://support.perchwell.com/baldwin/en/articles/16221347-how-to-tag-individual-listings) explains how to add and remove listings. [Link a Saved Search to a Tag](http://support.perchwell.com/baldwin/en/articles/16221382-how-to-link-a-saved-search-to-a-tag) covers how to link and unlink a saved search.

# Tag statuses, My Tags, and Client Tags

The Status column on the Tags page shows whether a Tag has contacts and whether they have been invited:
- My Tag: The Tag has no contacts. It holds listings for your own use or for sharing with no client attached, such as this weekend's open houses posted on social media.
- Not Sent: Contacts have been added, but they have not been invited to the Tag.
- Sent: The contacts have been invited to the Tag. The status includes the date the invitation was sent, such as Sent 10/19/26.

A Tag with one or more contacts is a Client Tag. Adding a contact changes the status from My Tag to Not Sent, and inviting them changes it to Sent. Contacts cannot be removed after they are saved to a Tag, so a Client Tag cannot go back to My Tag.

When Reactions are on, contacts on a Client Tag can like or dislike listings on its public page.

[Share a Tag with Clients](http://support.perchwell.com/baldwin/en/articles/16221617-how-to-share-a-tag) explains how to add contacts and send a Tag.

# Sort, filter, and rearrange columns on the Tags page

Click Tags in the top navigation to open the Tags page, which lists your Tags with their contacts, status, views, and reactions.

Click a column header to sort by that column. Click it again to reverse the sort, or a third time to remove it. To sort by multiple columns, click each header in order of priority. A number beside each header shows its sort order.

Click the filter icon in the Name, Contacts, or Status column header, then select the values you want to show. The filter icon to the right of the Columns menu offers the same filters.

Click the Columns menu above the table to choose which columns display. Drag a column header to a new position. The order saves automatically.

# Create, open, share, or edit a Tag on the Tags page

Click New Tag in the upper right of the Tags page to create a Tag. Open, share, or edit an existing Tag from the Actions column:
- Copy public link: Click the chain-link icon to copy the Tag's public link.
- Open public link: Click the arrow icon to open the Tag's public page in a new tab. Clicking the Tag's name in the Name column does the same. The Views column counts every visit, including your own.
- Edit tag: Click the pencil icon to change the Tag's name, description, listings, saved searches, or settings.
- Send or Resend: Click Send to invite the Tag's contacts, or to add contacts and invite them. Click Resend to add contacts or send the Tag again. Every contact receives the email each time.

[Create and Edit a Tag](http://support.perchwell.com/baldwin/en/articles/16221240-how-to-create-a-tag) covers each Tag setting, and [Share a Tag with Clients](http://support.perchwell.com/baldwin/en/articles/16221617-how-to-share-a-tag) explains how to add contacts and send a Tag.

# Tag listings and find Tags across Perchwell

Outside the Tags page, tag listings and find your Tags in these areas of Perchwell:
- Search: Select listings, click Actions, then select Share to add them to a Tag.
- Listing Detail Page: See the Tags a listing belongs to below Views. Click Actions, then select Share to add the listing to another Tag.
- Dashboard: Click a Tag in the Tags widget to open its public page. In the Listings widget, click the tag icon next to a listing to add it to a Tag.
- Contacts: Create a Tag for a contact with the Create Tag toggle in the Create New Contact window. Listings shared with a contact through a Tag appear under Shared Listings on their details page.

[Add Listings to a Tag](http://support.perchwell.com/baldwin/en/articles/16221347-how-to-tag-individual-listings) explains each way to add listings to a Tag.

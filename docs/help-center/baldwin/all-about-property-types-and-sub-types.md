# All About Property Types and Sub-Types

Use this article to choose the right property type when you add a listing and to find the property type to filter by when you search.

# Where to choose a property type in Perchwell

Choose a property type in the Property type field on the Add/Edit form when you add a listing. On the Search page, filter by property type with the Property Type Quick Filter. Both list the same six property types and the same subtypes under each. Members who came from a legacy platform may know Property Type as Class and subtypes as Property Type.

# What the Residential-Single Family property type includes

The Residential-Single Family property type includes detached and attached homes for sale. Attached means sharing a common wall with another unit, as a condo does. Residential-Single Family also includes deeded boat slips and garages that do not require owning property in the same development, and fractional ownership properties. Members who came from a legacy platform may know these three as the Other class.

Subtypes under Residential-Single Family:
- Residential attached
- Residential detached
- Boat slip
- Garage
- Fractional ownership

# What the Lease property type includes

The Lease property type includes homes and land for rent. Land under Lease is land without a building. Lease has no Multi-family subtype. List a multi-family rental under the Lease property type with the Residential attached subtype.

Subtypes under Lease:
- Residential attached
- Residential detached
- Land

# What the Lots and Land property type includes

The Lots and Land property type includes parcels for sale, such as residential and RV lots.

Subtypes under Lots and Land:
- Multi-family
- Mobile home
- Residential lots
- RV lot improved
- RV lot unimproved
- Zoned
- Land

# What the Multi-family property type includes

The Multi-family property type includes residential buildings with two or more units, such as a duplex with two units or a triplex with three. Multi-family is also a subtype under Commercial Sale, Commercial Lease, and Lots and Land. Choose the Multi-family property type when you list an entire residential building with multiple units for sale, rather than an individual unit. Choose the Multi-family subtype only when the property falls under Commercial Sale, Commercial Lease, or Lots and Land.

Subtypes under Multi-family:
- 4-10
- Duplex
- Townhome
- Triplex

# What the Commercial Sale and Commercial Lease property types include

The Commercial Sale property type includes commercial properties for purchase, such as office, retail, or industrial spaces. The Commercial Lease property type includes the same kinds of properties for lease. Both have the same subtypes.

Subtypes under Commercial Sale and Commercial Lease:
- Farm/ranch
- Hospitality
- Industrial
- Office
- Retail
- Special purpose
- Vacant land
- Multi-family
- Other

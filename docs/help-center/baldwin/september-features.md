# September Features

**Absorption Rate and Months of Supply:** Both metrics are back in the Market Analytics Report on a calculation that counts a listing as inventory only on days it is Active.

➡️ **[Learn More](https://support.perchwell.com/baldwin/en/articles/13623210-analytics-tab-overview)**

**Dotloop Integration:** Start a loop from a listing page with the address and MLS identifiers already filled in.

➡️ **[Learn More](https://support.perchwell.com/baldwin/en/articles/16776673-dotloop-integration)**

**Editable Text Messages:** When you share a listing by text, you now write your own message. The listing link and opt-out line are added for you.

➡️ **[Learn More](https://support.perchwell.com/baldwin/en/articles/13903326-share-multiple-listings-in-perchwell)**

**Listing History in the Full Report:** The Full Report now includes the listing's History section, so status and price changes print with the rest of the listing.

➡️ **[Learn More](https://support.perchwell.com/baldwin/en/articles/12816757-create-and-share-full-reports)**

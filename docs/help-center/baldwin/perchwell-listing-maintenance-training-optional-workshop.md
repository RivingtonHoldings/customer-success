# Perchwell Listing Maintenance Training & Optional Workshop

This session covers how to manage listings in Perchwell. For the first hour, we’ll walk through adding a new listing, editing and maintaining listing details, and handling status changes from active to pending to sold. In the second hour, we will have you add a new listing draft to Perchwell. We’ll also review mobile tools for updating listings on the go.

# Common Perchwell FAQs

## Does it matter if I use the map search or filters first?

No, both work together. The map itself acts as a filter, so you can use it at any point in your search.

## How many charts can I have in Search Analytics?

You can display up to **8 charts** at a time.

## How are similar listings determined on the listing details page?

Perchwell identifies similar listings based on factors like **location, square footage, number of bedrooms, school district, and other key features**.

## What should I enter if the year built is unknown?

If documentation is unavailable (for example, due to storm damage), use your best estimate:
- If the foundation was completely removed, treat it as a **new build**
- If the slab remains, use the **original construction year of the slab**
- Include any updates or rebuild details in the property description

## How do I add videos or Matterport tours?

You don’t upload videos directly. Instead, add the link in the Add/Edit form under:
- Virtual Tour #1
- Virtual Tour #2
- Branded Virtual Tour

## What is an “invited client”?

An invited client is someone who can log into Perchwell and collaborate with you. They can:
- Search listings
- Message you
- Save and tag properties

## What is a contact group?

A contact group helps you organize your contacts by role or stage—for example:
- Buyers
- Sellers
- Prospects
- Vendors (photographers, videographers, etc.)

## How can I control what sections clients see in reports?

You can collapse sections using the arrow next to each one. Collapsed sections will not appear in the **full report** shared with clients.

## Where does Autofill get its information in the Add/Edit form?

Autofill pulls from **tax records, CRS data, and other public records**.

## What is the maximum timeframe for a hot sheet?

You can set a hot sheet for up to **998 days**.

## Are analytics saved when I save a search?

Yes, analytics are saved along with your search.

## How do I search for a specific street name?

Go to the **Street** field and enter the name in quotation marks.

Example: “Fairhope Avenue”

## How do I unhide listings?

Click the **eyeball icon**, then select the listings you want to unhide.

## Can I add notes on the listing details page from desktop?

Not yet—but this feature is coming soon.

## Can I add contacts directly from my phone?

Not at this time.

## What happens when I duplicate a listing?

All listing details are duplicated.

## Can I search by school zone?

Yes, you can search using school-related filters.

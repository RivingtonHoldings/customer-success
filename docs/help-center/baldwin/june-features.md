# June Features

**Ranking Report Drill Down:** Click any total in the Agent, Office, or Firm Ranking reports to see the listings behind the number.

➡️ **[Check it out](https://www.perchwell.com/analytics)**

**Address Autocomplete:** Start typing an address in Add/Edit and Perchwell fills in the street, unit, city, state, and ZIP, with a map pin you can adjust.

➡️ **[Learn More](https://support.perchwell.com/baldwin/en/articles/13627189-add-and-edit-listings)**

**Brokerage Email Templates:** Brokers can set default message templates for contacting agents, inviting clients, emailing reports, and sharing listings, so every agent starts from the same copy.

➡️ **[Learn More](https://support.perchwell.com/baldwin/en/articles/15653156-create-communication-templates-for-your-brokerage)**

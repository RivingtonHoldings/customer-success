# Listing Detail Page Overview

# **Listing Detail Page Overview**

Use the Listing Detail page to review a listing, share it with clients, and create reports.
- Review MLS listing data including price, beds, baths, and open house details.
- Browse photos, floor plans, and videos.
- Generate client-ready PDFs and shareable links.
- Use tools like Auto CMA, Add Tag, or Copy Link.
- Launch integrated tools like RPR, ShowingTime, and Down Payment Resource.

# **Key Details**

Located below the image carousel, Key Details surfaces the most essential property information at a glance.
- Asking Price
- Association Fees
- Full listing address
- DOM and CDOM
- Bedrooms
- Bathrooms
- Square footage
- Year built

# **Property Summary**

The Property Summary lets you view additional key details at a glance, including Lot Size, Property Type, HOA, Property Subtype, and more.

# **Collapsible Tiles**

Listing data is organized into collapsible tiles. Tap a tile to expand it and review details, or collapse it to keep the page focused.
​
These collapsible tiles include information related to:
- Property Information
- Documents: You will be able to view and download any available **Documents **attached to the Listing
- Property Details
- Features
- Agents
- Financials
- History
​

## **Listing Details (Agent-Only)**

This section is available to registered agents only and can include:
- Private remarks
- Listing price and key dates
- Concessions (when available)
- Showing details
- Listing agent contact information

## **Property Details (Interior, Exterior, Lot)**

Use these tiles to review the property layout and site details.
- **Interior:** Review levels, rooms, appliances, and living area information.
- **Exterior:** Review structure type, pool features, fencing, parking, and architectural details.
- **Land and Lot:** Review MLS area, county, tax ID, year built, lot features, zoning, and more.

## **Location Tools**

Use Location to explore the map and nearby context.
- **Map Layers:** Tap to switch between default, satellite, and terrain views.
- **Street View:** Tap to view street-level imagery of the property.
- **Directions:** Tap to open Google Maps for instant directions to the listing.

## **History (Price and Status Changes)**

Use History to track updates made while the listing is on the market.
- **Listing History Details:** Review major status and price changes over time.
- **Change Log Details:** Review a detailed log of every change, including Date, Type, Price, DOM (Days on Market), and Changed By.

**💡 Tip: Key prices and statuses may differ slightly between the two History views.**

## **Mortgage and Taxes**

Use Mortgage and Taxes to estimate affordability for a listing.
- Review Monthly and Lifetime payment calculations.
- Adjust inputs like down payment, interest rate, sale price, and loan term.

# **Listing Options**

Tap the **three dots** on a listing to open the options panel, where you can share listings, create reports, and launch integrations.

## **Action Window**

#### **Share**
-

#### **Send via Email:** Share the listing with any contact via email.
- **Send via Messages:** Share the listing with an invited client inside Perchwell.
- **Copy Link:** Copy an external link to share via text, email, or elsewhere.

#### **Reports**
- **Create Report:** Generate a CMA, Listing Report, or Show Sheet.
- **One Pager:** Create a client-ready PDF with a QR code linking to the full Listing Detail page.
- **Auto CMA:** Create a CMA using the current listing as the subject property alongside similar listings.

#### **Organize**
- **Add Note:** Add an internal note for yourself on a listing.
- **Add Tag:** Add the listing to a new or existing tag.

## **Integrations Window**

Launch third-party tools directly from the listing:
- **RPR:** Access property reports, valuation tools, and market analytics.
- **ShowingTime:** Schedule and manage showings.
- **Sentrilock:** Manage lockbox access.
- **InfoSparks:** View market statistics and charts.
- **CRS:** Access CRS integrations.
- **Down Payment Resource:** Identify potential buyer assistance programs.

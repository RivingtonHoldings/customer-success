# Offer Manager Integration

## In this article:

You will learn how to open ShowingTime's Offer Manager from a listing's **Listing Detail** **Page** in Perchwell and what the link needs in order to work.

# What the Offer Manager integration does

Managing offers on a listing happens in ShowingTime's Offer Manager. Before this integration, that meant leaving Perchwell, opening ShowingTime, and finding the listing again before reviewing its offers. The **Offer Manager** link on the Listing Detail page removes those steps: it opens Offer Manager through single sign-on, which means you arrive already signed in and already viewing the listing you started from.

# Open Offer Manager from a listing

### Steps:
1. Open a Baldwin listing's **Listing Detail** page [confirm: the release note calls this the "Property Details page"; confirming the link lives on the Listing Detail page as named in the help center]
2. Click **Offer Manager** [confirm: where the link sits on the page, for step wording and the screenshot]
3. Review the listing's offers in ShowingTime's Offer Manager

ShowingTime opens signed in and scoped to that listing, which means there is no separate ShowingTime login and no searching for the listing a second time.

# Create a Search with Filters in Perchwell

# Start a new search
1. Click** Start New**
2. Enter a name for your search

New searches by default select the statuses** active **and **coming soon.**

# Build your search with **Filters**

Add filters to create a search.
​
​

## Using the Filter Filter Results:
- Start tying your keyword into the Search Bar.
- The search will automatically generate all possible filters that match your keywords.

💡**Note**: To find listings that recently came back on the market, set Current Status to Active and set Listing Activity to Went into contract with a 90-day trailing window.

📖 Visit this **[article](http://support.perchwell.com/baldwin/en/articles/11010696-understand-status-and-activity-filter)** to learn more about **Current Status** and **Listing Activity**.

# Use Map Tools for Unique Location Searches

Use map tools when a client has specific location requirements outside of the standard location filters.
- **Radius:** Draw a search area within a set number of miles from a specific location, such as a workplace or school.
- **Commute:** Find listings within a set commute time from a location. Choose the commute type: Walking, Driving, or Biking.
- **Freehand:** Outline a custom area directly on the map. Use this when a client wants to search within a boundary that does not follow standard neighborhood or zone lines.
- **Overlapping Boundaries:** Search within the shared area of two different locations. Use this when a client needs to stay close to more than one place, such as a workplace and a family member's home.

📖 Learn more [here](http://support.perchwell.com/p/34b8b9e0143880adb5d0e99524c3d3fa?pvs=25) about using our Map Tools.

# Add more filters to match specific criteria

Search the full library of search filters in the **Filters** view.

From the **Search** page:
1. Click the **Filters** tab.
2. Use the search bar to locate the filter you want.
3. Your filter should appear, where you can enter your criteria.

# Refining Filters further with OR, AND, or NOT

[![AND, OR, or NOT filter options](https://downloads.intercomcdn.com/i/o/trq7czv5/2501651720/9d304aca60af30a5eb3abfa54928/Group+122.png)](https://downloads.intercomcdn.com/i/o/trq7czv5/2501651720/9d304aca60af30a5eb3abfa54928/Group+122.png?expires=1788542100&signature=ef263f34910b942e2db8c3db8c9d4428471776254c1079eb09badf6d65a7018b&req=diUnF897nIZdWfMW1HO4zYCW2Mve3Uxswwz9wfCEMrUFuP%2FsWWJV1H2znxIb%0AEugPgNW%2FESUqyql6QkI%3D%0A)

Use the OR, AND, or NOT drop-down to include or exclude specific filter values and narrow your results.
- **OR:** Returns listings that **match at least one** of the selected options for that filter.
- **AND:** Returns listings that **match all** of the selected options for that filter.
- **NOT:** Returns listings that **do not match** any of the selected options for that filter.

# Organize your results using Filter Columns

## Rearrange Filter Columns

Every filter you add also appears as a column in your Search view, where you can adjust directly from the results grid.
​

Use filter columns to:
- Click Search to view listing results
- Click into the **Columns** drop down
- Drag and drop columns to reorder your view
- Remove filters with one click, by selecting or unselecting the checkboxes

💡**Save your column order as a template search so future searches start with your preferred layout.**

## Sort Listings

You can sort your results by clicking on any column header. Sorting works in a layered order, meaning the last column you click becomes your primary sort.

## Steps:
1. Click a column header to sort by that field
2. Click additional column headers to layer your sorting
3. To clear a sort, click the number next to the column header and then click the arrow to remove it

💡The **arrows** reflect ascending or descending order. The **numbers** reflect the sorting order.

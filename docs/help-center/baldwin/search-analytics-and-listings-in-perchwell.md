# Search, Analytics, and Listings in Perchwell

This session covers how to use search in Perchwell, including creating search templates, running searches for clients, sorting results, and using bulk actions. You’ll also learn how to navigate listing detail pages, export results, share listings with clients, and use search on mobile. Ends with live Q&A.

# Customize Your Search Defaults with Template Searches

# How to use a Template Search

A **Template Search** keeps your preferred search filter setup so you do not have to rebuild it each time.
- Save your selected filters
- Save your results column order
- Save your **Map** view settings
- Save your results display settings in **Listing** view
​

​

# Template Search setup

Build your search with your desired filters.

## Step 1: Search configuration
1. Click **Search** in the navigation bar.
2. Switch to the **Filters** view, to apply the filters you want to use by default.
3. Adjust your **Map** view and **Listing** view settings.
4. Reorder columns and add or remove columns in your results. Save the **column template** if it’s different than the existing column template.

## Step 2: Save the search
1. Click **Save.**
2. Enter a name for the saved search.

## Step 3: Assign your new search as a template
1. Click **My Searches**, to view your search list.
2. Find the saved search you just created.
3. Click the **star** icon next to the search name.

# New searches with template settings

When you start a new search, Perchwell applies your template settings automatically. Click **New Search** to start with your template’s filters, columns, and display settings.

You can adjust filters after you start a new search without changing your template. The **Save** button will have an orange dot when changes were made. Click **Save New** to save the new search.

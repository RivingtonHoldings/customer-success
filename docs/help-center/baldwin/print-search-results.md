# Print your search results as a PDF

Print uses the search criteria you already built, so set up your filters and columns the way you want them to appear before you start.

### Steps:
1. Go to **Search**
2. Apply filters to define the listings you want to print
3. Click **Actions**
4. Click **Print**

> **Tip**: Use fewer columns to keep the page clean and easy to read. Landscape works best with only the columns you need.

# Choose a layout and select save as PDF

The print window belongs to your browser, so the exact wording varies a little between Chrome, Safari, and Edge.
- Select **Landscape** for a horizontal page. This gives your columns more room across the width.
- Select **Portrait** for a vertical page.
- Click **Print** to send the results to a printer, or set the destination to **Save as PDF** to create a file you can share or keep.

# Control which columns appear in your PDF

Your printout matches the columns in your Search results table, in the same order. Adjust them before you print:
- Drag and drop column headers to reorder columns
- Add a column using the column dropdown
- Remove columns you do not need for this printout

Every column you display has to fit across the page, so a long column list prints narrow and can be hard to read. Trim to the columns that matter for the conversation you are printing for.

To learn how to create a columns templates, view our help center article here: [https://support.perchwell.com/baldwin/en/articles/11962073-customize-your-search-view](https://support.perchwell.com/baldwin/en/articles/11962073-customize-your-search-view)

# Control which listings appear

Print includes every listing in your current search results. To leave a listing out, hide the listings before you print:

### Steps:
1. Select the checkbox next to the listings you want to leave out
2. Click **Actions**
3. Select **Hide**

Hidden listings no longer appear in your current search results, so they will not appear in your printout either.

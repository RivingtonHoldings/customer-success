# Print or Save Search Results as a PDF

Use this article to choose which columns print and exclude listings from the printout, then print search results or save them as a PDF (Portable Document Format).

[Embedded video](https://www.loom.com/embed/f856f0802d414a71995c5e2dd77e9101)

# Choose which search results columns print

Add, remove, or reorder columns in the Columns menu above your search results to choose what prints. The printout matches them, in the same order.

Location and Status cannot be removed, so both columns always print. Photos are left out, including in Expanded view. All the columns share the page width, so a long list prints narrow and can be hard to read.

> **Tip:** Print 8 or fewer columns. Fewer columns print in a larger font that is easier to read.

[Customize Your Search Results View](http://support.perchwell.com/baldwin/en/articles/11962073-customize-your-search-view) covers adding, removing, and reordering columns, and saving them as a column template.

# Exclude listings from your search results printout

Hide listings on the Results tab to exclude them from the printout. To print only a few listings, check them and select Keep in the Actions menu to hide the rest.

## Steps:
1. Select the checkbox next to each listing you want to exclude
2. Click Actions
3. Select Hide

The hidden listings no longer appear in your search results and do not print.

> **Important:** Hide and Keep apply only while you remain in the search. If you reload the page or leave without saving the search, the hidden listings return to your results.

# Print search results from the Search page

Print your search results from the Actions menu on the Results tab of the Search page. Print turns on once at least one listing is selected.

Print is available in List and Expanded views. In Tiles view, switch to List or Expanded first.

## Steps:
1. Select the checkbox next to any listing
2. Click Actions
3. Select Print

Your browser's print window opens with a preview. The printout includes every listing in your search results, regardless of which listings are selected, including any not yet loaded on the page.

# Choose a page layout and print or save search results as a PDF

Choose the page layout and save your search results as a PDF from your browser's print window. Landscape gives columns more room across the page. Labels vary slightly between browsers such as Chrome, Safari, and Edge.

## Steps:
1. Select Landscape or Portrait under Layout
2. Select a printer under Destination, or select Save as PDF
3. Click Print, or Save if Destination is set to Save as PDF

Your search results print, or the PDF saves to your computer.

# Tags Overview

# When to Use Tags

Tags help you group listings so you can track changes and share a curated set of properties with clients. Also known as collections, carts, and Folders in similar platforms.

# **Add Listings to a Tag**

Add listings to a new or existing tag directly from Search or a Listing Detail Page.

## **Add a Listing from Search**

### **Steps:**
1. Tap **Search** in the bottom navigation
2. Switch to the **Listings** view
3. Tap the checkbox next to the listings you want to tag
4. Tap **Actions**
5. Choose **Add tag**
6. Select an existing tag or create a new one
7. Tags are highlighted when successfully added

## **Add a Listing from the Listing Detail Page**

### **Steps:**
1. Open the Listing Detail Page
2. Tap the t**hree dots** in the top right corner
3. Select **Add Tag**
4. Select an existing tag or create a new one
5. Tags are highlighted when successfully added

4. Tap **Show Items in Selected Tags** to view the listings inside

# **Share Tags with Clients**

Share a public link that opens a branded page with all the listings in your tag.

## **Copy and Share a Tag Link**

### **Steps:**
1. Tap Tags in the bottom navigation
2. Find the tag you want to share
3. Tap the three dots next to the tag name
4. Choose Copy Link
5. Send the link by text or email, or post it on your website

**💡 Tip: The link copies to your clipboard automatically.**

## **What Clients See in the Shared Tag View**

The shared page shows a client-friendly view of the listings in your tag.

# **Tag Alert Management**

Tag Alerts send agent-only notifications when listings in a tag change. Customize which alerts you receive for each tag.

## **Configure Tag Alerts**

### **Steps:**
1. Tap the **three dots** next to the tag
2. Choose **Edit tag**
3. Toggle each Alert Setting to customize when you are notified:
  1. Price Changes
  2. Status Change
  3. New Listings

**💡 Tip: quickly turn alerts on or off, tap the three dots next to the tag and select Turn On Alerts or Turn Off Alerts.**

# **What Is Included in Alert Emails**

#### Each alert email includes:
- A subject line with the listing address and type of update
- A link to the Listing Detail page
- A link to the tag folder
- A short summary of what changed

## **View and Update Tag Settings**

### **Steps:**
1. Tap **Tags** in the bottom navigation
2. Tap the **three dots** next to the tag
3. Choose **Edit tag** to access:
  1. Tag name
  2. Copy shareable link
  3. Customize alerts
  4. Delete or Duplicate

## **Tips**
- Share one tag link to highlight a curated set of listings for a client, your website, or social channels. The tag name will appear on the shared page.
- Turn on Tag Alerts when you want to monitor listing changes without re-running the same search.
- Tag Alerts notify agents only. Clients do not receive these emails.

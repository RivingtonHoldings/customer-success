# Perchwell Quick Start Training & Workshop

Whether you're new to Perchwell or looking for a refresher, this session covers how to get started with the platform and the key workflows you'll use most often.

The first hour is instructor-led training focused on core navigation and essential workflows. The second hour is a workshop where you can practice the same workflows, ask questions, and get additional support.

This live session fulfills your Learning Management System course requirement. Complete this session and you will not need to complete the LMS courses.

# Filter Your Search by Property Types

# Filter listings using **Property Type**

Use **Property Type** to narrow results by listing category.

With **Property Type**, you can:
- Select one or more categories (example: **Residential- single family**, **Lease**, **Commercial Sale**).
- Combine **Property Type** with other filters to narrow results further.
- See results update automatically as you select options.

To apply the filter:
1. Go to the **Search** page
2. In the Search header, click the **Property Type** dropdown
3. Select one or more property types

# Property types available in Baldwin

The options you see depend on your MLS feed. Baldwin property types may include:

| **Residential- single family** | Single-family homes and attached residential properties intended for individual ownership or occupancy. |
|---|---|
| **Lease** | Residential properties available for rent. |
| **Commercial Sale** | Commercial properties for purchase, such as office, retail, or industrial spaces. |
| **Commercial Lease** | Commercial properties available for lease. |
| **Lots and Land** | Vacant lots or undeveloped parcels. |
| **Multi-Family** | Residential properties with two or more units intended for rental or income-producing use. |

# Refine a property type (use **Edit**)

Some property types include subtypes. Use **Edit** to narrow results further.
​

To refine your selection:
1. Select a property type
2. Click the dropdown arrow next to the property type
3. Select the subtype options you want

When you refine property types, you may also be able to:
- Include listings without a specified subtype.
- Exclude listings without a specified subtype.

## Tips
- Do not select sales and rentals in the same search.
  - To review both together, add listings to the same tag, then open the tag from the **Tags** page.
- Review your subtype settings if results look too broad or too narrow.

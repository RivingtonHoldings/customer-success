# Filter Your Search with Keywords

# Filter listings by exact keywords (use the **Text** filter)

Use the **Text** filter to narrow results based on words that appear in a listing’s description and address.

To get the most accurate results:
- Put quotation marks around exact phrases you want to match (example: **"high ceilings"**).
- Use one or more quoted phrases to target specific features (example: **"accessible washer dryer"**, **"pet-friendly"**, **"doorman"**).

#
Run a keyword search
  1. Open the **Filters** **Tab.**
  2. Search for the **Text** filter.
  3. In the **Text Search** field, type your keyword or quoted phrase (example: **"high ceilings"**).
  4. Use **OR** to consider all entry options or **NOT** to exclude results.

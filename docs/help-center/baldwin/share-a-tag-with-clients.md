# Share a Tag with Clients

Use this article to send or resend a Tag by email, copy its public link, and understand how clients view and react to listings on the shared Tag page. Members who came from a legacy platform may know Tags as Listing Carts.

[Embedded video](https://www.loom.com/embed/c98bdf808cbd42b48b794e8720bb9a34)

# Email a Tag to clients or resend it

Email a Tag to clients from the Tags page, or resend a Tag you already sent to add more contacts. Start from the Actions column next to the Tag:
- Send: Click Send for a Tag you have not sent yet.
- Resend: Click Resend for a Tag you have already sent.

[![image](https://perchwell.intercom-attachments-1.com/i/o/trq7czv5/2785598819/687b1a601882480a504159535990/upload_748142938584749142.png)](https://perchwell.intercom-attachments-1.com/i/o/trq7czv5/2785598819/687b1a601882480a504159535990/upload_748142938584749142.png?expires=1793826000&signature=37c8276ab59baf756f97cd0dd35f1259fbed45d38476669e9bd465e7e162baca&req=dicvE8x3lYleUPMW1HO4zbHmtjWHdu3mnjyk%2BEJ9CinRF3lHmY1AKCkVeLi9%0ArYaOtnkbywmwkW15RXs%3D%0A)

> **Important:** A contact cannot be removed from a Tag after you save or send it. To stop sharing the Tag, delete it. Its public link then stops working for everyone.

## Steps:
1. Click Add next to Contacts in the Share your tag window
2. Select the checkbox next to each contact in the Add contacts window
3. Click Add again
4. Click Invite to workspace

The Tag invitation sent window lists the email address each invitation went to. On the Tags page, the Status column changes to Sent, and the Send button becomes Resend.

Each client receives an email from [no-reply@perchwell.com](mailto:no-reply@perchwell.com) with your name displayed as the sender. It includes a View Tag button that opens the Tag's public page.

[![image](https://perchwell.intercom-attachments-1.com/i/o/trq7czv5/2785598869/992671ce7333f31a75b05da0b940/upload_12181564527068668310.png)](https://perchwell.intercom-attachments-1.com/i/o/trq7czv5/2785598869/992671ce7333f31a75b05da0b940/upload_12181564527068668310.png?expires=1793826000&signature=23808c39014f9449ad6c7ca12c998c8259331d0aff2a399b793690a90a14d60a&req=dicvE8x3lYlZUPMW1HO4zdOXVpxWp7wVHpd%2BHkJ%2FSjd4TU5MLTgMGitE%2F91R%0Ajfp0tgYs8XLfy4JH2b0%3D%0A)

When you resend a Tag, all of its contacts receive the email again. If you are not adding anyone, click Invite to workspace when the Share your tag window opens.

The Share your tag window also includes these options:
- Save and Close: Adds contacts to the Tag without emailing them. This option is available only before you send the Tag.
- Contacts: Click the x next to a contact's name to remove them before you save or send the Tag.
- New Contact: Click New Contact in the Add contacts window to create a contact.
- Template: The email starts with the Welcome to Your Tag subject and message. Select Ask for feedback or Schedule a visit to replace the Subject and Message fields with the template text, or select None to clear both fields.
- Subject and Message: Edit the email before sending it. Both fields are required. The Subject holds up to 225 characters, and the Message holds up to 10,000.

When Tag notifications are on, the Tag's contacts also receive its notification emails. [Create and Edit a Tag](http://support.perchwell.com/baldwin/en/articles/16221240-how-to-create-a-tag) explains how to manage Tag notifications and delete a Tag.

# Copy or open a Tag's public link

Click the Copy public link chain-link icon in the Actions column on the Tags page to copy a Tag's public link. A "Copied to clipboard" message appears in the lower right. Paste the link into a text, an email, or anywhere else you want to share the Tag.

[![image](https://perchwell.intercom-attachments-1.com/i/o/trq7czv5/2785598913/4d2c83f20f991a89f99915e9a0d0/upload_9752655887824112693.png)](https://perchwell.intercom-attachments-1.com/i/o/trq7czv5/2785598913/4d2c83f20f991a89f99915e9a0d0/upload_9752655887824112693.png?expires=1793826000&signature=bd5172788744dea49b82f736802cdf5568bbc3257d1fffc02e51574d36ad4b19&req=dicvE8x3lYheWvMW1HO4zYtZWhMRm%2BBL5aCdO9BKzP9wnTrEbB%2Fz0G7azKQ6%0AZxhII4ABoh4fODZ%2B%2B0c%3D%0A)

To view the Tag's public page yourself, click the Open public link arrow icon in the Actions column. It opens in a new tab. The number in the Views column goes up each time someone visits the public page. Your own visits count too.

# What clients see and do on a shared Tag page

Clients do not need a Perchwell account or login to open a shared Tag page. It shows your name, contact information, and brokerage logo above the Tag's name, description, and listings. Clients can open each listing's details and move between them without leaving the page.

[![image](https://perchwell.intercom-attachments-1.com/i/o/trq7czv5/2785598962/978cd9babbbff7f00a7669dd09c2/upload_10534327622046806166.png)](https://perchwell.intercom-attachments-1.com/i/o/trq7czv5/2785598962/978cd9babbbff7f00a7669dd09c2/upload_10534327622046806166.png?expires=1793826000&signature=191453c59440303db1d3f1e142ccb954250de43683406ca3d7fbbb2d2d0ef4c2&req=dicvE8x3lYhZW%2FMW1HO4zQgPW2tJrnwBc%2FaArg%2FauNGJVyWc7HCu1kQi08qv%0AVLfRJ8TixB0LhsItWqk%3D%0A)

When the Reactions setting is on and the Tag has a contact, clients can like or dislike listings with the heart and thumbs-down icons. Clicking the selected icon again removes the reaction. The Liked and Disliked columns on the Tags page show the number of reactions for each Tag.

Reactions are on by default. [Create and Edit a Tag](http://support.perchwell.com/baldwin/en/articles/16221240-how-to-create-a-tag) explains how to turn them off. [Link a Saved Search to a Tag](http://support.perchwell.com/baldwin/en/articles/16221382-how-to-link-a-saved-search-to-a-tag) explains how a reaction affects a listing added through a linked saved search.

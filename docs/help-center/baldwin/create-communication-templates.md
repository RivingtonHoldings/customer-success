# Create Communication Templates

# What email templates are used for

Email templates help you send consistent messages without rewriting the same email each time.

## Create templates to:
- Invite clients to Perchwell
- Send report emails (CMA, itinerary, or listing)
- Email a listing agent

[Embedded video](https://demo.arcade.software/opAqykYFV4Y9Co4vJdYA?embed)

## Email template creation

Create templates from **Settings** so they are ready to use when you send emails.

### Steps:
1. Open **Settings**
2. Click **Email Copy Templates**
3. In **Invited Clients**, click **+ Add Template**
4. Enter a template name and write your message in the body field
5. Click **Save**

After you save a template, it appears as an option the next time you invite a client.

Add a personalized signature to your outgoing emails.

## **Steps:**
1. Open **Settings**
2. Select **Signature** in the left panel
3. Use the editor to create your email signature
4. Click **Save**

Your signature will now appear automatically at the bottom of any email sent using that template.

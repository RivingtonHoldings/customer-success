# Listings FAQ

# What time frame do the association fees reflect?

Perchwell displays whatever the agent has provided (annual, monthly, quarterly, etc.), but you will see the monthly fee amount at the top of the Listing Details Page.

# Where does the QR code on the one-pager take someone?

If you generate a client one-pager, the QR code takes the recipient to the client-facing Listing Details Page. It will not show any agent-only details. If you create an agent one-pager, the QR code takes the agent to the agent view of the Listing Details Page (as long as they're an agent in Perchwell).

# How are similar listings determined on the listing details page?

Perchwell identifies similar listings based on factors like **location, square footage, number of bedrooms, school district, and other key features**.

# Can my clients see the remarks on an open house?

No. Open house remarks are agent-only, which means clients and contacts do not see them on the listing detail page, in a shared listing, or on a public link. Other agents see them in the **Showings** card and the **Upcoming Showings** dialog.

# Can I add notes on the listing details page from desktop?

Not at this time, but this feature is coming soon.
